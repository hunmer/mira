📖 使用说明

协议 URL 格式

Mira 协议 URL 的标准格式为:

mira://?json=<base64编码的JSON数据>

JSON 数据结构:

{
  "type": "处理器类型",
  "data": {
    // 具体数据内容
  }
}

集成到渲染进程

在渲染进程中，你可以这样使用这些功能:

// 注册协议处理器
window.electronAPI.protocol.registerHandler('my_type', `
  console.log('收到协议数据:', data);
  // 处理数据...
`);

// 创建协议 URL
const url = await window.electronAPI.protocol.createUrl('server_import', {
  serverUrl: 'http://localhost:3001',
  name: '本地服务器'
});

// 托盘设置
await window.electronAPI.tray.updateSettings({
  enabled: true,
  clickAction: 'toggle'
});
