📖 使用说明

协议格式说明:

标准格式: mira://?json=<base64编码的JSON数据>

JSON 数据结构:

{
  "type": "协议处理器类型",
  "data": {
    // 具体的数据内容
  }
}

常用协议类型:

  • server_import: 服务器配置导入
  • plugin_install: 插件安装
  • share_collection: 收藏分享
  • file_share: 文件分享

注意事项:

  • JSON 数据必须是有效的格式
  • 生成的 URL 会自动进行 Base64 编码
  • 协议链接可以在支持 mira:// 的应用中打开
  • 此工具仅用于测试，不会实际触发协议处理
