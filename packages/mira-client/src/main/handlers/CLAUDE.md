## PluginHandler 详解

插件系统核心处理:
1. 插件安装/卸载生命周期
2. 插件 API 暴露（通过 IPC）
3. 插件安全沙箱管理
4. 插件配置管理

## DragDropHandler 详解

拖拽文件处理:
1. 监听 `drop` 事件
2. 验证文件类型
3. 触发文件导入流程
4. 通知渲染进程
