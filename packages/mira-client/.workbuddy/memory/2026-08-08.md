## 修复"dropdown 阴影只在 hover item 时显示"
- 根因：main.css 全局规则 `*:focus, *:focus-visible { box-shadow: none !important }`。浮层面板打开时 reka-ui 将焦点移到面板自身 → :focus 命中 → 阴影被清除；hover item 后焦点移到 item，面板 :focus 失效 → 阴影恢复。
- 修复：main.css 中针对 [data-slot="dropdown-menu-content"/sub-content、context-menu、popover、select、hover-card 的 content]:focus 加例外规则，box-shadow 复用 --tw-inset-shadow/--tw-ring-shadow/--tw-shadow 等 Tailwind 变量组合 + !important（特异性 0,2,0 > *:focus 的 0,1,0）。
- 教训：该项目全局杀 focus box-shadow，任何浮层阴影不生效先查这条规则。
