## 修复 ServerStartupLoading.vue 的 loader-3 复刻
- 问题：cube 是扁的。原因：旧实现用 skew 伪 2.5D 画法 + 整体 rotateX/rotateZ，且只用一个共用 keyframes + delay，与原版不符。
- 原版出处：uiverse.io/Timeless-Eve/itchy-dingo-13（loader-3）。registry json 只含 keyframes，基础样式需从 uiverse 页面 HTML 里提取。
- 原版要点：.loader 200x320 preserve-3d（自身不旋转）；每个 .box 有独立 left/top + --x/--y；.box>div 48x48 等距旋转（rotateY(-47) rotateX(-15) rotateZ(15)），::before rotateX(90) / ::after rotateY(90) 构成立方体侧面（brightness 1.2/1.4）；每个 boxN 用独立 box-moveN/box-scaleN keyframes；还有 .loader::before/::after 遮罩（背景色 = 页面背景）和 .ground 大地面 + shine。
- 修复：重写 Vue scoped 样式为原版 1:1 移植，颜色用 --primary（oklch 完整色值，可直接用），遮罩用 --background。项目变量是完整颜色而非 HSL 通道，这点已确认。
- 生成了 loader3-preview.html 独立预览页供快速验证。
