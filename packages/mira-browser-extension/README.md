# mira-browser-extension

Mira 网页采集扩展(Chrome MV3)。网页素材采集入口:截图、拖拽/右键上传、图片悬停收藏、资源嗅探、高清大图升级,统一上传到 Mira 素材库。

> 当前版本 0.0.1,要求 Chrome 116+(offscreen API)。

## 商店简介(一句话)

- 中文:一键截图、拖拽收藏网页图片视频,批量嗅探保存素材到你的 Mira 素材库。
- English: Capture screenshots, drag & drop images, and sniff web media straight into your Mira library.

## 功能概览

### 采集

- **截图**:可视区域 / 整页拼接 / 选区框选,支持快捷键与右键扩展图标入口
- **拖拽上传**:拖文件/网页图片到面板或页面浮层,可指定文件夹;浮层悬停边缘自动滚动
- **右键收藏**:页面图片右键「Mira · 收藏到素材库」
- **图片悬停菜单**:悬停图片显示 dots 按钮,菜单内直接导入
- **资源嗅探**:自动收集页面图片/视频/音频,列表/瀑布流视图,尺寸与宽高比过滤,多选上传或打包下载 zip
- **高清大图升级(maxurl)**:上传前自动解析原图,替换缩略图;规则可编辑(JSON)
- **自动滚动**:按间隔滚动触发懒加载,嗅探更多资源(50 屏上限)

### 管理与界面

- 多服务器管理:增删改、测试连接、快速切换
- 素材库/文件夹/标签浏览与搜索,树形新建/删除
- 批量上传(新窗口)、快速上传到根目录
- 上传队列:进度、取消、默认标签
- UI 模式 popup / 侧边栏;主题 auto/light/dark;中英文界面

## 开发

pnpm install
pnpm --filter mira-browser-extension dev   # vite + @crxjs HMR,加载 dist/ 到 chrome://extensions

## 构建

pnpm --filter mira-browser-extension build  # 产物在 dist/,可直接加载

## 加载扩展

1. `pnpm --filter mira-browser-extension build`
2. 打开 `chrome://extensions`
3. 开启右上角「开发者模式」
4. 点「加载已解压的扩展程序」,选择 `dist/` 目录
5. 扩展出现在列表中,无报错;点工具栏 Mira 图标即可使用

## 手动验证清单

加载扩展并连接到 Mira 后端后,逐项验证。Chrome API 与 UI 无法自动化测试,以此清单为验收 gate。

### 连接与服务器

- [ ] 点图标 → popup 出现 → 显示连接表单
- [ ] 输入服务器地址 + 账密 → 连接 → 状态灯变绿 → 出现素材库下拉
- [ ] 错误账密 → 显示错误信息,不崩溃
- [ ] 服务器管理:新增/编辑/删除服务器,测试连接,切换后自动重连

### 上传

- [ ] 拖文件到拖放区 → 进入队列 → 上传成功 → 10s 后移除
- [ ] 点拖放区 / 「点击选择」→ 文件选择器 → 选择文件 → 进入队列上传
- [ ] 网页拖起图片 → 弹出浮层(左:不设文件夹 / 右:文件夹列表) → 拖到某区上传到对应位置
- [ ] 拖图浮层悬停视口顶/底或文件夹列表顶/底 → 自动滚动
- [ ] 右键图片 → 「Mira · 收藏到素材库」→ 上传到当前库
- [ ] 悬停图片 → 右上角 dots 按钮 → 菜单点导入 → 上传成功
- [ ] 右键扩展图标 → 截图三件套快捷入口
- [ ] Header「批量上传(新窗口)」→ 新窗口批量上传
- [ ] 上传中点取消 → 任务停止

### 截图

- [ ] 可视区域截图 → 上传队列出现 `screenshot-xxx.png`
- [ ] 整页截图 → 滚动后上传拼接图(fixed 元素重复为已知限制)
- [ ] 选区截图 → 框选后上传裁剪图;Esc 取消
- [ ] chrome:// 页截图 → 提示不支持
- [ ] 快捷键 commands(可视/整页/选区) → 触发对应截图

### 嗅探

- [ ] 开启嗅探 → 资源列表出现图片/视频/音频
- [ ] 开启后刷新页面 / 新开 tab → 嗅探自动启用(开关已持久化)
- [ ] 目标标签页切换「全部 / 当前」→ 列表来源正确
- [ ] 视图切换列表 / 瀑布流;排序正序 / 倒序
- [ ] 尺寸过滤(最小宽高、宽高比)→ 只显示达标图片
- [ ] 多选 → 「上传选中」→ 队列出现;「下载选中」→ 打包 zip 下载
- [ ] 关闭嗅探 → 列表不再增长

### 高清大图升级(maxurl)

- [ ] 设置页开启「高清大图升级」→ 拖网页缩略图上传 → 落库为原图(非缩略图)
- [ ] 关闭开关 → 上传原图 URL(不升级)
- [ ] 编辑替换规则(JSON) → 保存生效;非法 JSON → 报错不保存

### 界面 / 偏好

- [ ] 切换 UI 模式 → side panel / popup 生效
- [ ] Header 主题按钮 → auto/light/dark 循环,刷新后记住;auto 跟随系统
- [ ] 切换语言中/英 → 界面文案切换,刷新后记住
- [ ] 重新登录 → 仍记得上次选择的素材库(不再清空)
- [ ] 改默认标签 → 上传的文件带标签
- [ ] 改批量导入并发数(1–10) → 生效
- [ ] 关闭拖拽按钮 → 页面拖图不弹浮层
- [ ] 关闭图片悬停菜单 → 悬停图片不显示 dots 按钮

### 自动滚动

- [ ] 开启自动滚动 → 页面自动滚到底 → 停止
- [ ] 无限流页面 → 滚到 50 屏上限停止
- [ ] 调整滚动间隔(ms) → 生效
