# mira_thumb_imagemagick

ImageMagick 缩略图生成插件。扩展服务端内置 ThumbnailService，支持 PSD/AI/EPS/SVG/TIFF/DNG/HEIC 等专业格式。通过 `thumbnailService.registerGenerator()` 注册。
