## 目标
将单一的「插件市场源地址」改为「插件市场源列表」（多个源），并支持在「插件市场」Tab 中通过 Select 切换当前生效的源。

## 数据模型设计（最小侵入）

在 `settings.ts` 的 `AppSettings` 中：
- **保留** `clientPluginMarketUrl: string` 作为「当前生效/选中的源」（plugin store 与 PluginsDialog 已依赖它，保留可零改动对接）
- **新增** `clientPluginMarketUrls: string[]` 作为「已配置源列表」

这样 `plugin.ts` 里的 `fetchMarketplaceCatalog` / `installMarketplacePlugin` 无需改动逻辑（它们继续读 `clientPluginMarketUrl` 作为当前源），只需由 UI 来维护「选中源」写入该字段。

## 改动清单

### 1. `packages/mira-client/src/renderer/stores/settings.ts`
- `AppSettings` 接口新增 `clientPluginMarketUrls: string[]`，`clientPluginMarketUrl` 保留并注释为「当前选中源」。
- 两处默认值（初始 `settings` 与 `resetSettings` 的 `defaultSettings`）各新增 `clientPluginMarketUrls: []`。
- 在 `loadSettings()` 合并 `{ ...settings.value, ...parsed }` 之后，加入**向后兼容迁移**：
  - 若 `clientPluginMarketUrls` 为空但旧的单值 `clientPluginMarketUrl` 存在，则迁移为 `[clientPluginMarketUrl]`。
  - 确保 `clientPluginMarketUrl` 一定在 `clientPluginMarketUrls` 列表中（若不在则回退到列表第一项）。

### 2. `packages/mira-client/src/renderer/views/settings/pluginPlan.vue`
把「市场源地址」区块从单个 Input 改为**可编辑列表**：
- 新增响应式 `clientPluginMarketUrls: string[]`、`newMarketUrl: string`（用于「添加」输入框）。
- `loadCurrentSettings` 中读取 `currentSettings.clientPluginMarketUrls`（含旧值 `clientPluginMarketUrl` 迁移兜底）。
- 列表项：每行一个 Input（绑定该 URL）+ 删除按钮（`pi pi-trash` / `Button variant="ghost" size="icon-sm"`）；底部一个「添加」Input + 「添加」按钮，校验非空且去重。
- 任何改动都调用 `saveMarketUrls()`：把列表 trim、去空、去重后写入 `settingsStore.updateSettings({ clientPluginMarketUrls, clientPluginMarketUrl })`，并保证「当前选中源」仍在列表内（否则设为列表首项）。
- `confirmReset` 重置时清空列表与新增框。
- 复用已有的 `Button` / `Input` 组件，保持现有视觉风格。

### 3. `packages/mira-client/src/renderer/components/business/PluginsDialog.vue`
在「插件市场」Tab（`v-else` 区块）顶部、原「未配置市场源/加载中/列表」之前，插入一个**源切换 Select**：
- 仅当 `activeTab === 'online'` 显示。
- 选项来自 `settingsStore.settings.clientPluginMarketUrls`，SelectValue 显示当前 `marketplaceUrl`。
- Select 组件使用项目已有的 `@/components/ui/select`（与 pluginPlan.vue 一致的导入方式）。
- 切换时调用新方法 `switchMarketSource(url)`：通过 `settingsStore.updateSetting('clientPluginMarketUrl', url)` 持久化选中源 → 既有 `watch(marketplaceUrl)` 会自动触发 `loadMarketplace()` 重新拉取目录（无需额外加载逻辑）。
- 顶部操作栏（搜索/刷新/添加）与 Select 共存：将 Select 放在内容区顶部独立一行（贴左边），避免与 header 工具栏挤压。

## 不变项
- `plugin.ts` store 的市场逻辑保持不变（继续读 `clientPluginMarketUrl` 作为当前源）。
- `MarketplacePluginEntry` 类型、安装流程不变。

## 验证
- 构建无 TS 报错（新增字段在接口、两处默认值均已声明）。
- 旧配置用户：升级后单个 URL 自动迁移进列表且仍为选中源，「插件市场」Tab 正常加载。
- 设置页：可增删源并保存，列表持久化。
- PluginsDialog：切换 Select 后自动刷新市场目录；无源时仍显示「未配置」提示。
