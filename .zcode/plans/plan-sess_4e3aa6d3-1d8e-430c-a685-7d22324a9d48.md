## HomeSidebar.vue 重写后（~60 行编排壳）
```
<script setup>
  import SidebarLibrarySelector from './SidebarLibrarySelector.vue'
  import SidebarToolbar from './SidebarToolbar.vue'
  import SidebarModuleList from './SidebarModuleList.vue'
  const props = defineProps<{ homeController; tags; libraryId }>()
  // 原样透传 15 个 emit 声明，供 v-bind="$attrs" 无法覆盖的具名事件使用
  const emit = defineEmits<{ ...15 个原 emit... }>()
  // 转发 locateItem
  const moduleListRef = ref<{ locateItem: (...) => Promise<void> }>()
  defineExpose({ locateItem: (...args) => moduleListRef.value?.locateItem(...args) })
</script>
<template>
  <SidebarLibrarySelector @show-about="emit('showAbout')" ... />
  <SidebarToolbar @upload="emit('upload')" ... />
  <SidebarModuleList ref="moduleListRef" :home-controller=... @folder-select="emit('folderSelect', $event)" ... />
</template>
```
- 注意：各子组件的事件用显式 `@event="emit('event', $event)"` 透传（而非依赖 `v-bind="$attrs"`），保证类型清晰、参数透传不丢。
