## 方案 A：后端补 file_count，前端递归求和展示

### 目标
让 `FolderTreeComponent` 右侧的素材数量 badge 显示真实值（当前后端从不返回 fileCount，导致恒为 0 / 不显示）。

### 改动清单（5 个文件）

#### 1. 后端 SQL — `packages/mira-app-core/src/storage/sqlite/mixins/FolderOperations.ts`
`getAllFolders`（第 183 行）改为带相关子查询：
```ts
const rows = await this.getSql(
  `SELECT f.*,
    (SELECT COUNT(*) FROM files WHERE folder_id = f.id AND recycled = 0) AS file_count
   FROM folders f ORDER BY sort_index ASC, id ASC`,
  []
);
```
- `recycled = 0` 排除回收站文件，与"全部"分类语义一致
- 子查询只统计该文件夹**直接**所属文件，递归总数交给前端

#### 2. 后端索引 — `packages/mira-app-core/src/storage/sqlite/LibraryServerDataSQLite.ts`
initialize() 的建表/防御性 ALTER 之后追加（`CREATE INDEX IF NOT EXISTS` 幂等，老库安全）：
```sql
CREATE INDEX IF NOT EXISTS idx_files_folder_recycled ON files(folder_id, recycled)
```
- 没索引时 N 个文件夹 → N 次全表扫描 files，几万文件会卡几百 ms；加索引后降到几十 ms 内

#### 3. SDK 类型 — `packages/mira-app-core/src/shared/sdk/modules/FolderModule.ts`
`Folder` 接口（第 7-16 行）增加可选字段：
```ts
file_count?: number;
```

#### 4. 前端 Store 类型 — `packages/mira-client/src/renderer/stores/folder.ts`
`Folder` 接口（第 6-17 行）增加可选字段：
```ts
file_count?: number
```
（原有 `fileCount?: number` 保留，兼容其它读取处）

#### 5. 前端递归求和 — `packages/mira-client/src/renderer/controllers/HomeController/dataManager.ts`
`buildFolderTree`（第 87-103 行）把 count 改为递归求和：
```ts
const children = buildFolderTree(folders, folder.id, depth + 1)
const selfCount = folder.file_count ?? folder.fileCount ?? 0
const totalCount = selfCount + children.reduce((s, c) => s + (c.count || 0), 0)
return {
  ...,
  count: totalCount,        // 父文件夹显示含所有子层级的总数
  children: children.length > 0 ? children : undefined,
  ...
}
```
- 叶子节点 count = 自身文件数；父节点 = 所有后代之和（侧栏 badge 直觉）
- 兼容 `file_count`（后端新字段）和 `fileCount`（旧引用，如 AnimatedFolderCard.vue / useFolderTagPanel.ts）

### 不需要改动
- 路由层 `/api/folders/all`：透传 core 返回值，自动带 file_count
- Store `fetchFolders`：`...folder` 直接展开，file_count 自动进 store
- `FolderTreeComponent` 模板：已有 `v-if="node.count"` 渲染逻辑，count=0 时不显示 badge（空文件夹无噪音，行为合理）

### 不在本次范围（已知缺口，完成后单独提示）
上传文件、移动文件到文件夹、给文件打标签等操作目前不触发 `refreshFolders`，badge 不会实时更新——会在下次 folder refresh（切库/建删文件夹/点刷新按钮）时同步。若要这些操作后也实时更新，需在 `fileOperations.ts` 补几处 refresh 调用，属独立的增量工作。

### 验证
- 启动后端 + 前端，打开任意含文件的素材库，侧栏文件夹右侧应显示数字
- 父文件夹数字 = 自身 + 所有子文件夹数字之和
- 回收站内的文件不计入
- 空文件夹不显示 badge
