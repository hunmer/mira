## 任务
参考 `VideoPreview.vue` 的 header 结构重写 `AudioPreview.vue`，并把参考的 React 版 `MusicPlayer` 完整移植为 Vue 3 版本作为新的音乐播放器组件。范围：**单文件播放**（tracks 仅含当前文件 1 项），**完整移植所有视觉效果**（旋转唱片、ScalesMixer 鳞片动画、Web Audio 频谱可视化、转场音效、进度条、控件、键盘快捷键）。

## 关键决策
- **路径别名**：用户贴的 `@/components/ui/...` 是 React demo 写法。本项目 renderer 别名是 `@renderer/`（见 `VideoPlayerComponent.vue` 用法），故组件置于 `src/renderer/components/ui/music-player-widget/`，导出路径用 `@renderer/components/ui/music-player-widget`。
- **多 track 控件处理**：单文件下 `tracks.length === 1`，切歌/随机/循环相关控件（prev/next/shuffle/loop）在 `length <= 1` 时**隐藏**，只保留播放/暂停 + 进度条 + 唱片 + 鳞片可视化 + 音轨信息。保留底层多 track 逻辑（与参考一致），便于将来扩展为播放列表模式。
- **封面/标题/艺术家来源**：封面优先 `fileInfo.thumbnailPath`，缺失时用渐变占位 + 音符图标；标题用 `fileInfo.name`（去扩展名）；艺术家/专辑从 `fileInfo.metadata?.artist` 防御性读取，缺失时用 i18n fallback。**不引入** ID3 解析依赖（后续优化）。
- **HLS 兼容**：`useAudioPlayer` 的 loadTrack/初始化中，若 src 含 `.m3u8` 且 `Hls.isSupported()` 则走 hls.js，否则直接 `audio.src=`。保留原 AudioPreview 的 HLS 销毁逻辑。
- **crossOrigin 风险**：默认**不设置** `crossOrigin`（避免破坏本地/Electron 播放）。`useAudioAnalyser` 已用 try/catch 包裹 `createMediaElementSource`，且 `ScalesMixer` 在无频谱数据时回退为正弦驱动动画，故可视化会优雅降级。仅当上层显式传 `crossOrigin="anonymous"` 才设置。
- **CSS 缺失**：参考只贴了 TSX。实现时先联网检索该组件原始 CSS（按 ScalesMixer/Disc/hole 等特征类名检索 magicui/21st.dev registry），找到即采用，找不到则按视觉描述自写完整样式（约 200-300 行 scoped CSS）。

## React → Vue 移植映射
| React 概念 | Vue 实现 |
|---|---|
| `useRafLoop` / `useTransitionSound` / `useAudioAnalyser` / `useAudioPlayer` / `useKeyboardShortcuts` | TS composables（`composables/*.ts`） |
| `useReducer(reducer,...)` 状态机 | `reactive()` + 普通函数操作（逻辑等价移植 shuffleOrder/reducer 分支） |
| `ScalesMixer` / `Disc` / `TrackInfo` / `ProgressBar` / `Controls` | 子组件 `.vue`（SFC） |
| `useRef` 数组（colRefs/circleRefs） | `ref<HTMLElement[]>([])` + `:ref` 回调 |
| `useId()` | `useId()`（Vue 3.5 原生支持） |
| raf 内直接改 `el.style.transform` | 同（ imperative DOM 写入，保持性能，避免每帧响应式开销） |

## 风险
- **CSS 缺失**：最不确定项，靠联网检索 + 自写兜底。
- **Web Audio CORS**：本地文件无 CORS 时频谱数据为 0，鳞片动画自动降级为纯时间驱动（功能不报错，仅不反映真实频谱）。
- **封面缺失**：大部分音频文件 `thumbnailPath` 为空，将显示占位（已设计）。

## 验收
1. 打开任意音频文件预览页 → 应见 PreviewHeader（文件名/大小/标签/打开方式）+ 黑胶唱片旋转 + 鳞片动画 + 进度条 + 播放按钮。
2. 点击播放 → 唱片旋转加速、鳞片动画随频谱跳动（若 CORS 允许）、进度条前进、时间显示。
3. 点击进度条任意位置 → 跳转播放。
4. 空格键 → 播放/暂停；左右箭头 → ±5s。
5. 切换不同音频文件（flac/mp3/wav/m3u8）→ 均能播放（HLS 格式走 hls.js）。
6. 切深色模式 → 配色跟随。
