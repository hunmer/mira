## 实现方案

将 React 版 `appearance-tab.tsx` 的「换主题 / 换配色 / 换风格」功能完整复刻到 `packages/mira-client/src/renderer/views/settings/GeneralPanel.vue`，沿用 mira-client 现有的 Pinia + ConfigStorage 持久化体系。

---

### 1. 新建 `theme-style.ts` 工具模块（移植自 `G:\agent_spaces\packages\web\src\lib\theme-style.ts`）

**路径**: `packages/mira-client/src/renderer/utils/theme-style.ts`

把 React 版的纯函数（不依赖 React）整体移植过来，保留同样的 DOM 行为：
- 导出常量 `THEME_STYLES`（mira/lyra/luma/rhea 四套 CSS 变量字符串）、`DEFAULT_PRIMARY_COLORS`、`PRIMARY_COLOR_KEY`、`THEME_STYLE_STORAGE_KEY`、`THEME_STYLE_CUSTOM_CSS_KEY`
- 导出函数 `applyThemeStyle(css)` / `removeThemeStyle()` / `applyPrimaryColor(color)` / `removePrimaryColor()`
- **裁掉字体相关逻辑**（Google Fonts 加载、`--app-font-*` 变量注入、字体拆分）—— 本任务只做主题/配色/风格，字体不在范围内，避免引入网络请求和无用代码
- **裁掉 `applySavedThemeStyle` / `applySavedPrimaryColor`**（它们读 localStorage）—— 改由 settingsStore 在 initialize 时驱动

迁移要点：`document.getElementById` / `document.createElement('style')` 等浏览器 API 在 Electron renderer 里可用，无需改动。

---

### 2. 扩展 settingsStore（`stores/settings.ts`）

**新增字段** 到 `AppSettings` 接口与默认值（含 `resetSettings` 的 `defaultSettings`）：
```ts
themeStyle: string        // '' | 'mira' | 'lyra' | 'luma' | 'rhea' | 'custom'，默认 ''
themeStyleCustomCss: string  // Custom 模式下的 CSS 文本，默认 ''
primaryColor: string      // 主色 hex，默认 ''（空表示用主题自带主色）
```

**初始化时应用**: 在 `initialize()` 的 `applyTheme()` 之后，调用新的内部方法 `applyThemeStyle()` 和 `applyPrimaryColor()`：
- 读 `settings.themeStyle`：若为 `custom` 用 `themeStyleCustomCss`，否则查 `THEME_STYLES`；为空则 `removeThemeStyle()`
- 读 `settings.primaryColor`：非空 `applyPrimaryColor(color)`，空则 `removePrimaryColor()`

**扩展 `updateSetting`**：对 `themeStyle` / `themeStyleCustomCss` / `primaryColor` 三个 key 增加分发逻辑，实时应用。沿用现有 `updateSetting` / `saveSettings` 流程，**不新增独立 localStorage key**。

注意：settingsStore 的 `applyTheme()` 只管 `.dark` class 的增删；新加的 `applyThemeStyle()` / `applyPrimaryColor()` 是独立的 `<style>` 注入，互不冲突。

---

### 3. 重写 `GeneralPanel.vue` 模板

布局调整为自上而下三个分区（替换现有「主题设置」分区，保留「本地化设置」）：

**(A) 主题（视觉卡片预览）**
- 三个 button 卡片：浅色 / 深色 / 自动（auto 对应 React 版 system）
- 每个卡片含一个 SVG 预览缩略图 + 文字标签
- SVG 用**内联 `fill` 属性**写死颜色（如 `fill="#ffffff"` / `fill="#0a0a0a"`），**不用 Tailwind 的 `fill-neutral-*` 类**——因为本仓 Tailwind 配置没有 neutral 调色板，硬套会失效
- 选中态：`ring-2 ring-primary` + 不透明度变化，对应 React 的 `ring-primary/48`

**(B) 配色（Primary Color）**
- 9 个预设主色圆点 + 1 个「自定义」圆点（虚线边框、内含 `+`，点击触发隐藏的 `<input type="color">`）
- 完全等价 React 版 `ColorPicker` 行为：点击预设 = 切换该色 / 取消（再点一次清空）；自定义圆点在已选自定义色时显示该色填充
- 圆点选中态用 `ring-2 ring-foreground` + scale-110

**(C) 风格（Style）**
- `Select` 下拉：Default / Mira / Lyra / Luma / Rhea / Custom
- 选 Custom 时显示 `Textarea`（等宽字体、最小高度 40）让用户粘贴 CSS
- 下方一行 link 按钮（`Button variant="link" size="sm"`）跳转 tweakcn.com，用 `ExternalLink` 图标

**(D) 保留本地化设置（语言）** 不动。

---

### 4. `<script setup>` 逻辑

- 引入 `useSettingsStore`、`useToast`、shadcn-vue 组件（`Select*`、`Textarea`、`Button`）、以及新工具模块的 `THEME_STYLES` / `DEFAULT_PRIMARY_COLORS` / `applyThemeStyle` / `removeThemeStyle` / `applyPrimaryColor` / `removePrimaryColor`
- 风格下拉的 options 数组、配色圆点数组在组件内定义
- 改造现有 `handleSettingChange(key, value)`：对 `theme` / `themeStyle` / `themeStyleCustomCss` / `primaryColor` 四种 key，先调 store 的 `updateSetting`（内部自动 apply + save），再 toast 提示。统一一个 handler 复用，沿用现有 toast 成功/失败反馈风格
- theme 卡片选中态绑定 `settingsStore.settings.theme`
- 主色绑定 `settingsStore.settings.primaryColor`；自定义取色器 `@input` 直接触发 handler
- Custom CSS textarea 用 `@update:model-value` 触发 handler（无需额外「应用」按钮，实时生效，与 React 版一致）

---

### 5. 不做的事 / 边界

- 不复刻字体（BUILTIN_FONTS、CustomFontDialog、Google Fonts 加载）——超出本任务范围
- 不改 Tailwind 配置（不补 neutral 调色板），SVG 颜色走内联属性
- 不引入新依赖；不新建 `ColorPicker.vue` / `SearchSelect.vue` 组件——直接在 GeneralPanel 内联（圆点逻辑简单，Select 已有）
- 不动 `ThemeSwitcherComponent.vue`（其他地方在用），只改 GeneralPanel
- 持久化全部走 `mira-settings` 这一个 ConfigStorage key，与现有体系一致

### 验证方式
- 启动 renderer，进入设置 → 通用：切换浅/深/自动主题，`.dark` class 实时切换
- 选 Mira/Lyra/Luma/Rhea，CSS 变量 `<style>` 注入，圆角/配色立即变化
- 选 Custom，粘贴 tweakcn 生成的 CSS，立即生效；刷新应用后保持
- 点主色调色板，`--primary` 等变量改变；再点一次取消
- 自定义取色器选任意色，主色实时更新
- 重启应用，所有选择从 settingsStore 恢复
