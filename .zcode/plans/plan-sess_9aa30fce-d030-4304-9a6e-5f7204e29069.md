# 悬浮球：减阴影 + 右键菜单（隐藏本次 / 始终隐藏 / 打开设置）

实现原生 Electron 右键菜单（与托盘菜单 TrayService 风格一致），同时减弱悬浮球的视觉阴影。

## 1. 减弱阴影（`floating-ball-window.html` 纯 CSS）

调暗/收紧以下阴影变量与规则，让悬浮球更轻盈：
- `--fb-shadow`：缩小偏移和扩散半径、降低不透明度（如 `0 4px 12px -3px rgba(79,70,229,0.35), 0 2px 6px -1px rgba(0,0,0,0.18)`）
- `--fb-shadow-drag`：同方向减弱（拖拽态保留略强但比现状收敛）
- `:root.dark` 下的 `--fb-shadow`：相应减弱
- `.folder-back` 的 `box-shadow`：弱化 `inset` 与外阴影
- `@keyframes fb-pulse`：把 `drop-shadow` 的半径/不透明度调小，呼吸更克制

不改尺寸/布局，只改阴影强度。

## 2. 渲染层：触发右键菜单（`floating-ball-window.js`）

- 把 `mounted` 里全局 `contextmenu preventDefault` 的行为，改成**只在悬浮球元素上弹出菜单**：
  - 在 `.floating-ball` 上加 `@contextmenu.prevent="handleContextMenu"`
  - 保留 body 级别的默认 `contextmenu preventDefault`（避免透明区域出系统菜单），但球上先于它处理
- `handleContextMenu(e)`：把鼠标**屏幕坐标**（`e.screenX/screenY`）随消息发给主进程：
  ```js
  bridge.send({ type: 'fb-context-menu', x: e.screenX, y: e.screenY, timestamp: Date.now() })
  ```
  （用 screen 坐标，主进程 `Menu.popup({x,y})` 即可定位，无需窗口偏移换算。）

## 3. 主进程：原生菜单（`FloatingBallWindowHandlers.ts`）

新增 messageHandler `'fb-context-menu'`，用 `Menu.buildFromTemplate + popup` 弹出三项菜单（沿用 TrayService 的写法，import `Menu` from electron）：

```ts
'fb-context-menu': (data) => {
  const menu = Menu.buildFromTemplate([
    { label: '隐藏本次', click: () => self.handler.hide() },          // 仅本次会话隐藏
    { label: '始终隐藏', click: () => self.forwardToMain({ type: 'fb-hide-always' }) }, // 持久化关闭
    { type: 'separator' },
    { label: '打开设置', click: () => self.openSettings() },          // 唤起主窗口+跳设置
  ])
  menu.popup({ x: Math.round(data.x || 0), y: Math.round(data.y || 0) })
}
```

新增私有方法（复用已有 `showMainWindow` + `forwardToMain`）：
```ts
private openSettings(): void {
  this.showMainWindow()
  this.forwardToMain({ type: 'fb-open-settings' })
}
```

说明：
- 「隐藏本次」=`handler.hide()`，下次启用设置/重启会恢复（符合"本次"语义）。
- 「始终隐藏」转发给主渲染进程，由它把 `floatingBallEnabled` 置为 false（设置持久化由现有 `settingsStore` watch 负责），窗口随之隐藏。
- 「打开设置」唤起主窗口并让主渲染进程 `router.push` 跳到悬浮球分区。

## 4. 主渲染进程：处理两个新消息（`HomeView/index.vue`）

在 `handleFloatingBallMessage` 增加分支：
```ts
} else if (data.type === 'fb-hide-always') {
  settingsStore.settings.floatingBallEnabled = false
  await handleSettingChange?.('floatingBallEnabled', false) // 走现有持久化链路
} else if (data.type === 'fb-open-settings') {
  router.push({ name: 'Settings', query: { tab: 'floating-ball' } })
}
```
（`fb-hide-always` 直接复用设置里的关闭逻辑；现有的 `watch(floatingBallEnabled)` 会触发 `floatingBall.hide()`，无需额外隐藏调用。）

## 5. SettingsView：读取 `tab` 查询参数（`SettingsView.vue`）

补一个既有的小缺口，让深链 `?tab=floating-ball` 生效：
```ts
import { useRoute } from 'vue-router'
const route = useRoute()
const activeSection = ref((route.query.tab as string) || 'overview')
// watch route.query.tab 以支持已挂载时的二次跳转
watch(() => route.query.tab, (tab) => { if (typeof tab === 'string') activeSection.value = tab })
```
（仅做高亮跳转，不改 `componentMap`；floating-ball 分区面板渲染是独立既有问题，不在本次范围。）
