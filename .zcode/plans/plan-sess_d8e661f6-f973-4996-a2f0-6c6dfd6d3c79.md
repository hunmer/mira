## 目标
在嗅探 Tab 为列表视图缩略图加 hovercard(浮动预览卡),瀑布流图片右上角加「查看大图」图标,点击/悬浮都进入全屏大图查看器(遮罩 + contain + 鼠标移动后关闭)。

## 复用的现有模式
- **模块级单例 ref + 单个 Teleport-to-body 宿主**(参考 `useDialog.ts` / `DialogHost.vue`):hovercard 和全屏查看器各建一套,host 在 `App.vue` 挂载一次。
- **视口翻转定位**(参考 `ContextMenu.vue` 的 posStyle computed):hovercard 跟随鼠标并做边界翻转。
- **全屏 overlay 壳**(参考 `SettingsOverlay.vue` 的 `.overlay`):全屏查看器复用 `position:fixed; inset:0` + mask 模式,z-index 用 `2000`(与 DialogHost 同级,最高)。
- 9 个 CSS 变量(`--bg/--bg-elev/--fg/--muted/--border/--primary/--primary-fg/--danger/--radius`)已在 `src/ui/style.css` 定义,直接用。
- 无新增依赖。

## 改动清单

### 新建 4 个文件

**1. `src/ui/composables/useImagePreview.ts`** — hovercard 单例
- 模块级 `const preview = ref<{ url: string; x: number; y: number } | null>(null)`
- `show(url, x, y)` / `hide()` / 暴露 `state`
- 用法:`@mouseenter` 调 show,`@mouseleave` 调 hide

**2. `src/ui/components/ui/ImageHovercard.vue`** — hovercard 宿主
- `<Teleport to="body">`,读 `useImagePreview().state`
- ~240px 宽卡片,`<img>` 原图(`loading="lazy"`)加 max-height 限制,底部小字显示 url 文件名
- 定位:跟随鼠标坐标,溢出视口右/下时翻转(同 ContextMenu 思路)
- pointer-events:none(不抢悬停,避免抖动);z-index 1500

**3. `src/ui/composables/useImageViewer.ts`** — 全屏查看器单例
- 模块级 `const viewer = ref<{ url: string } | null>(null)`
- `open(url)` / `close()` / 暴露 `state`

**4. `src/ui/components/ui/ImageViewer.vue`** — 全屏查看器
- `<Teleport to="body">`,固定遮罩 `position:fixed; inset:0; z-index:2000; background:#000c`
- 图片 `object-fit:contain; max-width/height:90vw/90vh`,右上角关闭按钮(×)
- **鼠标移动后关闭**实现:打开后设 600ms 宽限期(避免刚打开就被关),宽限期后绑定 `mousemove`/`touchmove` → close;同时支持 click 遮罩 / ESC 关闭(兜底,因为纯"移动即关"无法静止欣赏)
- `<img>` 加载中显示 loading 占位

### 编辑 4 个文件

**5. `src/ui/components/sniffer/ResourceItem.vue`**(列表视图缩略图)
- `<img class="thumb">` 加 `@mouseenter="onEnter" @mouseleave="onLeave" @mousemove="onMove"`
- 三个 handler 调 `useImagePreview().show(url, e.clientX, e.clientY)` / 更新坐标 / `hide()`
- 仅图片/有 poster 的视频才启用(`resource.kind === 'image' || (video && poster)`)

**6. `src/ui/components/sniffer/MasonryItem.vue`**(瀑布流)
- 同样给 `<img class="media">` 加 hover 处理(浮动预览卡,与列表一致)
- **右上角新增「查看大图」图标按钮**:`position:absolute; top:6px; right:6px`,hover 卡片时显示(opacity 过渡,与 `.meta` 同款),点击 `@click.stop="imageViewer.open(url)"` 打开全屏查看器
- 图标用放大镜 SVG,16px,半透明圆底(参考现有 `.check` 样式)
- 仅图片/有 poster 的视频渲染该图标

**7. `src/ui/App.vue`**
- 在 `<DialogHost />` 旁挂载 `<ImageHovercard />` 和 `<ImageViewer />`(始终挂载,不受 booting/authenticated 影响)

**8. i18n**(`src/ui/i18n/locales/zh-CN.ts` + `en.ts`)
- sniffer 下新增:
  - `viewLarge`: 查看大图 / View large
  - `previewHint`(可选,hovercard 内文件名下方): 来源提示复用现有

## 验证方式
- `cd packages/mira-browser-extension && pnpm dev`(或项目既定构建)构建扩展,加载后进入嗅探 Tab
- 列表视图:悬停缩略图 → 浮动预览卡出现并跟随,移开消失;边界翻转正确不溢出
- 瀑布流:悬停图片 → 浮动预览卡;右上角放大镜图标 hover 显示,点击 → 全屏查看器
- 全屏查看器:图片 contain 居中,移动鼠标(600ms 后)→ 关闭;点遮罩/ESC 也关闭
- 暗色/亮色主题下颜色正确(用 CSS 变量)
