# Spine 格式预览插件实现方案

## 概览
创建一对 MirA 格式扩展插件，复刻 3D 插件（`mira-3d-format-preview` / `mira_3d_format`）的架构：
- **客户端插件** `mira-spine-format-preview`：Spine 3.8 预览器（三栏布局，骨骼树只读查看+显隐切换，动画/皮肤/播放控制，无编辑功能）
- **服务端插件** `mira_spine_format`：用 spine-exporter CLI 渲染 idle 动作首帧 → PNG 缩略图

技术栈：Vue 3 + Vite + shadcn-vue（复用 3D 插件已 vendor 的 UI 组件）+ PIXI.js 7 + pixi-spine 3.8。

## 关键技术决策（基于调研确认）
1. **资源 URL 推导**：`FileInfo.url` 未被 SDK 填充。用 `file.localFile || file.path`（真实磁盘路径），经 `toPreviewUrl`（复用 3D 插件逻辑）转 `file:///`，然后替换扩展名推导同目录 `.atlas`/`.png`。
2. **vendor 运行时加载**：pixi 7.3.3 + pixi-spine 3.8 UMD 放 `public/vendor/`，构建时拷到 `dist/vendor/`，`index.html` 用 `<script>` 标签在模块脚本前加载（`base: './'` + `file://` 加载已验证可行）。
3. **缩略图 destPath**：恒为 `<libraryPath>/thumbs/<hash>.png`（已确认 `LibraryServerDataSQLite.ts:171`）。spine-exporter 输出到临时目录后移动到 destPath。
4. **无 CSP**：插件窗口 `file://` 下可 fetch 同级资源（3D GLTFLoader 已验证）。

### 核心移植要点
- **loader.ts**：从 `SpineLoader.js` 移植，删除 4.2 路由分支（`useSpine42`/`loadSpine42Runtime`/`getJsonSpineVersion` 的 4.x 检查），仅保留 SkeletonBinary + SkeletonJson（3.8）。保留 `loadSpine`、`getAnimations`、`getSkins`、`getBoneTree`、`BoneVisibility`（显隐切换所需）。
- **runtime.ts**：简化版 `runtime.js`。因 vendor 已通过 `<script>` 加载，`PIXI`/`pixiSpine`（即 `PIXI.spine`）已挂在 window。提供 `getPIXI()`/`getSpineRuntime()` 同步访问器 + Proxy 代理 `PIXI`，去除 fetch+eval 逻辑。
- **previewApp.ts**：移植 `SpinePreviewApp.js`（PIXI.Application + spineContainer + ticker + fitView），默认动画选 `idle`（优先）而非 `stand2`，否则首个。
- **BoneTree.vue**：移植 `SpineBoneTree`，保留展开/折叠 + 显隐 toggle（Eye/EyeOff），**删除 selectedBone/onSelect 选中高亮逻辑**（无变换面板），保留显隐状态。tree 改 Vue 递归组件实现（参考 jsx 的递归 BoneRow）。
- **资源加载流程**（App.vue）：
  1. 从 URL query 读 `skelUrl`/`atlasUrl`/`pngUrl`/`fileName`
  2. index.js 推导：`base = file.localFile 去扩展名`；`atlasUrl = base + '.atlas'`；`pngUrl = base + '.png'`；若文件本身就是 .atlas/.png 则回溯找 .skel
  3. fetch 三个 URL → loadSpine → SpinePreviewApp.setSpine

### index.js（格式注册）
```js
// extensions: ['skel'] （atlas/png 不单独注册，避免与图片缩略图冲突）
// renderHoverCard: iframe embed（dist/index.html?embed=1&skelUrl=&atlasUrl=&pngUrl=&fileId=）
//   失败/超时回退 file.thumbnailPath（PNG）
// open: api.window.openPluginWindow（独立窗口完整预览）
```
注意：只注册 `.skel` 扩展（atlas/png 是配套图片，不应接管）。hovercard 接收的是 .skel 文件的 FileInfo。

### UI 风格
- 复用 3D 插件 shadcn-vue 组件（button/badge/tabs/slider/switch/input/label/separator）+ 新增 `scrollarea`（骨骼树滚动）。
- 深色优先 style.css 复用。PIXI canvas 背景 `#eef0f3`（与参考项目一致，浅灰便于看清角色）。

## 第二部分：服务端插件 `plugins/plugins/mira_spine_format/`

### 目录结构
```
mira_spine_format/
├── package.json          # dep: spine-exporter；scripts: build(tsc)
├── tsconfig.json         # 复用 mira_3d_format
├── index.ts              # 注册格式 + thumbnail
└── data/config.json      # width/height/timeoutMs/animation（默认 idle）
```

### index.ts 核心逻辑（参考 mira_3d_format/index.ts）
```ts
registerFileFormat(pluginName, {
  id: 'mira_spine_format',
  extensions: ['skel'],
  mimeTypes: ['application/x-spine'],
  thumbnailExtensions: ['skel'],
  process: async (filePath) => { /* 解析返回骨骼/动画数（可选，用 fs 读 .skel 头部版本） */ },
  thumbnail: async (srcPath, destPath) => generateThumbnail(srcPath, destPath),
})
```

### generateThumbnail 流程
1. `fs.mkdirSync(dirname(destPath))`
2. 校验同目录存在 `<base>.atlas` + `<base>.png`（缺则跳过，日志告警，不抛错）
3. 创建临时输出目录 `os.tmpdir()/spine-<hash>`
4. 调用 `spine-export-cli`：
   ```
   spine-export-cli -e png -s idle -o <tmpDir> <skel所在目录>
   ```
   - `-e png` 导首帧，`-s idle` 选 idle 动作（exporter 找不到 idle 时渲染默认/首动画）
   - 用 `execFileAsync`，`process.execPath` + `require.resolve('spine-exporter/bin/...')` 或 `npx spine-export-cli`，`windowsHide:true`，`timeout:120s`
5. 在 tmpDir 找输出 PNG（匹配 `*idle*.png` 或 `*.png`，取首个），`fs.rename`/`copyFile` 到 destPath
6. 清理 tmpDir
7. 失败时 catch 记日志，不阻断（与 mira_3d_format 一致）

### 动画选择策略
- 优先 `idle`；若 exporter 因无该动画失败，回退不带 `-s`（渲染默认首动画）。config.json 可配 `animation: "idle"`。

### CLI 解析
- `resolveCli()`：先查 `config.renderCommand`，否则 `require.resolve('spine-exporter')` 找其 bin（按 npm 包实际入口调整，构建时验证）。备选 `npx`。

## 第三部分：市场索引 & 构建

1. **复制 vendor**：从 `G:\agent_spaces\...\src\vendor\spine\pixi-7.3.3.min.js` + `pixi-spine-3.8-4.0.6.js` 到插件 `public/vendor/`。
2. **客户端构建**：`cd plugin && pnpm install && pnpm exec vue-tsc --noEmit && pnpm run build`。
3. **服务端构建**：`cd plugin && pnpm install --ignore-workspace && pnpm run build`；服务端 `pnpm --filter mira-app-server exec tsc --noEmit`。
4. **市场索引**：`node scripts/build-client-plugins-index.mjs`（生成 plugins.json 含 dist sha256）。
5. **启用服务端插件**：在 `plugins/plugins/plugins.json` 加 `{name:"mira_spine_format", enabled:true, path:"mira_spine_format"}`。

## 验收步骤（最小可执行）
1. 把一个 spine 3.8 资源（character.skel + .atlas + .png 三件套）放入媒体库目录。
2. 重启服务端（procm-mcp）→ 扫描缩略图 → 确认 `thumbs/<hash>.png` 生成（idle 首帧）。
3. 客户端媒体网格：该 .skel 文件显示 spine 角色缩略图（非占位）。
4. hover 该文件：iframe 弹出 embed 预览，PIXI 渲染角色动画播放。
5. 双击打开独立窗口：三栏布局——左骨骼树（可展开/折叠/Eye 显隐）、中 canvas、右动画切换（选 idle 播放）+ 倍速 + 皮肤。验证骨骼隐藏后角色部件消失、恢复后重现。
6. 切换动画（如 walk）能播放对应动作；暂停/播放按钮生效。
