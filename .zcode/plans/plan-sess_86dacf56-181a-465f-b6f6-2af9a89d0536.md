## 一键部署 mira-app-server 到 WSL 方案

### 文件清单（3 个，放 `D:\mira_typescript\scripts\`）
1. **`deploy-mira-server.sh`** — WSL/Ubuntu 内的主部署脚本（bash，幂等）
2. **`deploy-mira-wsl.ps1`** — Windows 一键入口（PowerShell，自动装 Ubuntu + 调起 bash）
3. **`deploy-mira-wsl.cmd`** — 双击启动器（调用 PowerShell，无黑窗闪退）

### deploy-mira-server.sh 流程（幂等、可重复执行）
1. 断言 Linux 环境（防误在 docker-desktop 跑）
2. 检测 node ≥ 18；缺失则用 NodeSource 装 Node 20.x + npm
3. `npm install -g mira-app-server`（已装且版本一致则跳过）
4. 运行 `mira-app-server doctor`，缺失 ffmpeg/imagemagick/exiftool 时提示并询问是否 `doctor --install`（apt 自动装）
5. 后台启动 server：`nohup mira-app-server start --http-port 8081 --ws-port 8018 --data-path ~/.mira-data`，PID 写入 `~/.mira/mira-server.pid`，日志 `~/.mira/mira-server.log`
6. 轮询 `http://localhost:8081/health` 最多 30s，确认 ready
7. **引导用户创建第一个素材库**（交互式 prompt）：
   - 素材库名称（默认 `MyLibrary`）
   - 素材库磁盘路径（默认 `~/mira-libraries/my-library`，自动 `mkdir -p`）
   - 自动 `mira-app-server login -u admin -p admin123`
   - `mira-app-server libraries create -n <name> -p <path>`（新建库自动 start）
8. 打印访问信息：URL、账号 `admin/admin123`（提示改密）、library id、stop/restart 命令
9. **参数化支持非交互**：`--name`, `--path`, `--auto`, `--http-port`, `--ws-port`，便于自动化验证

### deploy-mira-wsl.ps1 流程
1. 检查 WSL2 启用
2. 检查 `Ubuntu` 发行版；不存在则 `wsl --install -d Ubuntu --no-launch`
3. 首次初始化：`wsl -d Ubuntu -u root echo ok`（触发 root 模式初始化，无需交互创建用户）
4. 透传参数到 `wsl -d Ubuntu -u root -- bash /mnt/d/mira_typescript/scripts/deploy-mira-server.sh ...`
5. 把脚本路径解析为 WSL 的 `/mnt/...` 形式

### deploy-mira-wsl.cmd
单行：`powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0deploy-mira-wsl.ps1" %*`

### 执行与验证（我会做的）
1. 写三个文件
2. 自动安装 Ubuntu 发行版（`--no-launch` + root 模式，非交互）
3. 在 WSL Ubuntu 内跑 `deploy-mira-server.sh --auto --name DemoLib --path ~/mira-libraries/demo`，确认：node 装上、mira-app-server 装上、doctor 跑通、server 起来 health ok、library 创建成功
4. 跑通后把 server 停掉（避免占用端口），把验证产出贴给用户

### 注意
- 首次 `wsl --install -d Ubuntu` + apt 装 ffmpeg/node 等耗时较长（5-15 min，看网速），属正常
- Windows defender / wsl kernel 更新可能要求管理员权限，ps1 会在需要时提示用户用管理员重开
- WSL 退出后 server 进程会被杀；脚本会打印如何后台常驻（systemd user service 可选，本次不做，留后续优化）
