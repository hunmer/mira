# 声明式 VeeValidate 表单组件 实现计划

## 目标
为 mira-client 增加一个**声明式（数据驱动）表单组件**：传入 Zod schema + 字段元数据数组，自动渲染全部字段、自动校验、提交。彻底替代现有 `FolderEditDialog` / `ServerEditDialog` 里大量手写的 `errors` ref + `validateForm()` + 重复模板。

依赖：`vee-validate` + `@vee-validate/zod` + `zod`（当前未安装，需加到 `package.json`）。

## 关键 API 调研结论（影响实现）
- **shadcn-vue 官方 form 组件**走的是「`useFormField()` 注入 + `<Form>`/`<FormField>` 从 vee-validate re-export」的路线。`Form.vue` 本身就是 vee-validate 的 `Form`，`index.ts` 直接 `export { Form, Field as FormField, FieldArray as FormFieldArray } from "vee-validate"`。
- **Select/RadioGroup/Checkbox/Slider** 值形状差异大，声明式渲染器需按字段类型分别绑定：
  - `Select`/`RadioGroup`：`modelValue` 是 string
  - `Slider`：`number[]`（单值滑块要 `[v]` ↔ `v` 适配）
  - `Checkbox`（布尔）：`modelValue: boolean | 'indeterminate'`
  - `CheckboxGroup`（多选 → string[]）：项目里**不存在**该组件，需在渲染器里用多个 `Checkbox` 组合，维护数组
  - `DatePicker`：`modelValue: Date | string`，emit `update:modelValue`，值是 Date
- 主题 token（`--destructive`/`--input`/`--ring`/`--primary`…）在 `main.css` 已定义，shadcn 组件类名可正常生效。
- ⚠️ `main.css` 全局 `*:focus { box-shadow:none!important }` 会吃掉 focus 环 —— 不在本任务范围，渲染器不强制恢复（如需视觉焦点后续单独处理）。

## 实施步骤

### 第 1 步：安装依赖
在 `packages/mira-client/package.json` 的 `dependencies` 增加：
```json
"vee-validate": "^4.13.0",
"@vee-validate/zod": "^4.13.0",
"zod": "^3.23.0"
```
（版本与 reka-ui / vue 3.5 兼容；执行 `pnpm install`）

### 第 2 步：补 shadcn-vue form 基础组件 → `src/components/ui/form/`
新增 8 个文件（来自 shadcn-vue new-york registry，`@/registry/new-york/ui/label` 改为 `@/components/ui/label`）：
- `injectionKeys.ts` — `FORM_ITEM_INJECTION_KEY`
- `useFormField.ts` — 注入 FieldContextKey，返回 `{ name, error, formItemId, formDescriptionId, formMessageId, valid, isDirty, isTouched }`
- `FormItem.vue` — `provide(FORM_ITEM_INJECTION_KEY, useId())`，`<div class="space-y-2">`
- `FormControl.vue` — `<Slot>` 透传 id/aria
- `FormLabel.vue` — error 时 `text-destructive`
- `FormDescription.vue` — `text-sm text-muted-foreground`
- `FormMessage.vue` — vee-validate `<ErrorMessage>`
- `index.ts` — 导出以上 + `export { Form, Field as FormField, FieldArray as FormFieldArray } from "vee-validate"`

### 第 3 步：声明式 `SchemaForm` 业务组件 → `src/renderer/components/business/SchemaForm/`
**核心文件：**
1. `types.ts` — 类型定义：
   ```ts
   export type FieldType = 'text'|'textarea'|'number'|'password'|'email'
     |'select'|'radio-group'|'checkbox-group'|'switch'|'checkbox'
     |'date'|'slider'
   export interface SelectOption { label: string; value: string | number; disabled?: boolean }
   export interface SchemaField {
     name: string                  // 对应 zod schema 的 key
     label: string
     type: FieldType
     description?: string
     placeholder?: string
     options?: SelectOption[]      // select/radio/checkbox-group 用
     defaultValue?: unknown
     // slider 专用
     min?: number; max?: number; step?: number
     // date 专用
     disabled?: boolean
     required?: boolean            // 仅用于 label 标记 *
     colSpan?: 1 | 2               // 网格布局，默认 1
   }
   export interface SchemaFormProps<T> {
     schema: z.ZodType<T>          // Zod schema（单一真源）
     fields: SchemaField[]
     initialValues?: Partial<T>
     title?: string; description?: string
     submitText?: string; cancelText?: string
     layout?: 'single' | 'grid'    // 默认 grid 双列
     submitting?: boolean
   }
   export interface SchemaFormEmits<T> {
     (e: 'submit', values: T): void
     (e: 'cancel'): void
     (e: 'invalid', errors: Record<string, string>): void
   }
   ```
2. `useSchemaForm.ts` — composable：
   - 用 `useForm({ validationSchema: toTypedSchema(props.schema), initialValues })` 建表单
   - `handleSubmit(onSubmit, onInvalid)` 包出 `onSubmit`
   - 导出 `submit`, `reset`, `values`, `errors`, `meta`
3. `FieldRenderer.vue` — **按 type 分发渲染的字段渲染器**（关键）：
   - 接收 `field: SchemaField`，内部用 `<FormField v-slot="{ value, handleChange, handleBlur, errorMessage, setValue }" :name="field.name">` 拿到 vee-validate 的 setter
   - `<FormItem><FormLabel>{{label}}<span v-if=required>*</span></FormLabel>`
   - 按 `field.type` switch 渲染对应 UI 组件，用 `handleChange` / `setValue` 回写：
     - text/password/email → `<Input :type>`
     - number → `<Input type="number">` + `Number()` 转换 + `setValue(v, false)`
     - textarea → `<Textarea>`
     - select → `<Select :model-value="value" @update:model-value="setValue">` + `<SelectTrigger/Content/Item>`
     - radio-group → `<RadioGroup :model-value="value" @update:model-value="setValue">` + items
     - switch → `<Switch :model-value="!!value" @update:model-value="v=>setValue(!!v)">`
     - checkbox（单布尔）→ `<Checkbox :model-value="!!value" @update:model-value="v=>setValue(!!v)">`
     - checkbox-group（多选 string[]）→ 组合多个 `<Checkbox>`，勾选时 `setValue(arr±val)`
     - date → `<DatePicker :model-value="value" @update:model-value="setValue">`
     - slider → `<Slider :model-value="value ?? []" @update:model-value="v=>setValue(v)">`（保留 number[] 形状）
   - `<FormControl>` 包裹控件，`<FormDescription>` + `<FormMessage>` 收尾
4. `SchemaForm.vue` — 主组件：
   ```vue
   <Form v-slot="{ meta }" :validation-schema="..." :initial-values="..." @submit="onSubmit" class="space-y-6">
     <div v-if="layout==='grid'" class="grid grid-cols-1 md:grid-cols-2 gap-4">
       <div v-for="f in fields" :class="f.colSpan===2 && 'md:col-span-2'"><FieldRenderer :field="f" /></div>
     </div>
     <!-- single 布局同上但单列 -->
     <div class="flex justify-end gap-3 pt-2">
       <Button type="button" variant="outline" @click="$emit('cancel')">{{ cancelText }}</Button>
       <Button type="submit" :disabled="submitting">{{ submitText }}</Button>
     </div>
   </Form>
   ```
5. `index.ts` — 导出 `SchemaForm`、`FieldRenderer`、`useSchemaForm`、所有类型

## 使用示例（落地后业务侧写法）
```vue
<script setup lang="ts">
import { z } from 'zod'
import { SchemaForm, type SchemaField } from '@/renderer/components/business/SchemaForm'

const schema = z.object({
  name: z.string().min(1, '请输入名称').max(100),
  url: z.string().url('请输入有效地址'),
  role: z.enum(['admin','user']),
  enabled: z.boolean().default(true),
  level: z.number().min(0).max(100),
  birthday: z.date().optional(),
  tags: z.array(z.string()).optional(),
})
const fields: SchemaField[] = [
  { name:'name', label:'名称', type:'text', required:true },
  { name:'url', label:'服务器地址', type:'text', placeholder:'http://...' },
  { name:'role', label:'角色', type:'select', options:[{label:'管理员',value:'admin'},{label:'用户',value:'user'}] },
  { name:'enabled', label:'启用', type:'switch' },
  { name:'level', label:'等级', type:'slider', min:0, max:100, step:1 },
  { name:'birthday', label:'生日', type:'date' },
  { name:'tags', label:'标签', type:'checkbox-group', options:[{label:'A',value:'a'},{label:'B',value:'b'}] },
]
const onSubmit = (v) => console.log('提交', v)   // v 已是强类型，且通过校验
</script>
<template><SchemaForm :schema="schema" :fields="fields" @submit="onSubmit" /></template>
```
