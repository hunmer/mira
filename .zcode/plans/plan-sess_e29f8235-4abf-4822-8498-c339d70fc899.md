给 TrayService 添加 i18n（主进程目前无任何 i18n 机制，渲染进程的 locale JSON 被打包进 bundle 无法被主进程读取，因此主进程需自带轻量字典）

## 改动清单（4 文件，1 新建）

### 1. 新建 `packages/mira-client/src/main/i18n/index.ts`（主进程轻量 i18n）
- 内置 zh-CN / en-US 字典，仅含主进程 UI 所需 key（tray.* 系列）。
- 导出：
  - `t(key)` — 翻译，缺 key 回退 zh-CN 再回退 key 本身。
  - `detectLocale()` — 基于 `app.getLocale()`，en 开头→`en-US`，否则 `zh-CN`。
  - `setMainLocale(locale)` / `getMainLocale()`。
- 不在模块加载时调用 detectLocale（避免 app 未 ready），由 TrayService.init 显式触发。

字典内容：
```
tray.resetPosition  重置位置 / Reset Position
tray.about          关于 Mira / About Mira
tray.quit           退出 / Quit
tray.tooltip        Mira 媒体库 / Mira Media Library
```

### 2. 修改 `packages/mira-client/src/main/services/TrayService.ts`
- import `t, setMainLocale, detectLocale`。
- `init()` 开头：`setMainLocale(detectLocale())`（此时 app 已 ready）。
- `createTray`：`setToolTip(t('tray.tooltip'))`。
- `updateContextMenu`：三个 label 全部改用 `t('tray.resetPosition')` / `t('tray.about')` / `t('tray.quit')`。
- 新增 `updateLocale(locale: MainLocale)`：setMainLocale → setToolTip → updateContextMenu，重建菜单。

### 3. 修改 `packages/mira-client/src/main/ipc/TrayHandlers.ts`
- `registerHandlers` 中新增：`ipcMain.on('tray:set-locale', (_e, locale) => this.trayService.updateLocale(locale))`。
- 与现有 `window:set-close-to-tray` 的 `ipcMain.on` 模式一致。

### 4. 修改 `packages/mira-client/src/renderer/stores/settings.ts`
- `loadSettings` 末尾（紧挨现有的 `send('window:set-close-to-tray', ...)`，~452 行）加：`window.electronAPI?.send('tray:set-locale', settings.value.language)` — 启动时把持久化语言同步给主进程。
- `updateSetting` 的 `language` 分支（~500 行）加：`window.electronAPI?.send('tray:set-locale', value as string)` — 运行时切换即时通知。

## 同步策略
- 主进程初始用系统语言（detectLocale）。
- 渲染进程 loadSettings 完成后立即纠正为用户持久化语言。
- 运行时切换语言即时重建托盘菜单。
- 全程复用现有 `window.electronAPI.send` ↔ `ipcMain.on` 通道模式，不引入新依赖。
