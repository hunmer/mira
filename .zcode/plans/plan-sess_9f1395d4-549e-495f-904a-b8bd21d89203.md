## 目标
复刻 `G:\agent_spaces\packages\web\src\components\ui\masonry.tsx` 为 Vue 3 版本，替换 `vue-waterfall-plugin-next`，让 `WaterfallComponent.vue` 支持宽图自动占多列。对外接口向后兼容，调用方（`MediaContentView.vue` / `MediaTabListView.vue`）零改动。

## 实施步骤

### 1. 新建 Masonry 通用组件
**文件**：`packages/mira-client/src/components/ui/masonry/Masonry.vue` + `index.ts`

Vue 3 `<script setup>` 复刻原 React `masonry.tsx` 的核心能力：
- **Props**：`data`、`renderItem`(用默认插槽 + scoped slot `v-slot="{ item, index }"`)、`getKey`、`getMeta`、`columns`(数字 / 响应式断点映射)、`gap`(默认 16)、`rowHeight`(默认 80)、`class`、`style`、`sortBy`、`enterAnimation`、`exitAnimation`、`staggerDelay`、`layoutTransition`、`lazyRootMargin`。
- **核心算法**（直接移植，与 React 版逐行对齐）：
  - `aspectToRatio(aspect)` —— 解析 `"16:9"` 等。
  - `resolveColumns(width, cols)` —— Tailwind 断点 `sm/md/lg/xl`。
  - `layout(...)` —— 贪心布局：每个 item 放到连续 `colSpan` 列中"当前最矮"起始列；高度优先级 `height > aspect > rowSpan×rowHeight`；返回 `{ items: PlacedItem[], totalHeight }`。
- **动画**：用 `motion-v` 的 `Motion`（每个 item 包裹 `:layout / :initial / :animate / :exit / :transition`）+ `AnimatePresence` 包裹列表，对齐 framer-motion 行为。`motion-v` 已在依赖里。
- **容器宽度**：`useResizeWidth` composable，用 `ResizeObserver` 测容器宽。
- **懒加载**：`LazyCell` —— `IntersectionObserver`（once），lazy=false 时直接渲染。保留 `lazyRootMargin`。
- **样式**：容器 `position: relative; height: totalHeight`；item `position: absolute; left/top/width/height`。
- **不实现**：`hasMore/onLoadMore/scrollContainerRef/loader`（当前项目分页在上层处理，无需内置），保持组件精简。注释里标注未移植项。

### 2. 改造 WaterfallComponent.vue
- 移除 `vue-waterfall-plugin-next` 的 import 与 `Waterfall` 标签。
- 改用自研 `<Masonry>`：容器 ref、`columns`(由 `columnsPerRow` 映射成响应式断点对象 `{ base:2, sm:..., 1200:columnsPerRow }`，对齐原 `breakpoints` 行为)、`gap`、`:get-meta`(根据 aspect 计算 colSpan)。
- **宽图占列逻辑**（在 `getMeta` 中实现，aspect 自动判定）：
  - 复用现有 `getItemRatio(item)`（已预加载真实缩略图比例 + hash fallback）。
  - 阈值（默认）：`aspect >= 1.6 → colSpan=2`；`aspect >= 2.4 → colSpan=3`；并 `Math.min(colSpan, columns-1)` 保证旁边还能放普通项。
  - 通过新增可选 props 暴露阈值：`wideAspectThreshold?: number`(默认 1.6)、`ultraWideAspectThreshold?: number`(默认 2.4)、`maxColSpan?: number`(默认 3)。
  - `meta` 传 `aspect: \`${ratio}:1\``（让 Masonry 按宽度算高度，多列时高度自动按比例放大）。
- **MediaWaterfallItem 适配**：其内部 `mediaContainerStyle` 用 `aspectRatio: ${ratio}/1`。Masonry 已通过 absolute 定位固定高度，需把 item 根节点改成 `h-full w-full` 填满定位框（改 `MediaWaterfallItem.vue` 的根 div class 加 `h-full`，并让内部 media 容器 `h-full` 而非依赖 aspect-ratio —— 因为 Masonry 已给定精确高度）。保留 ratio prop 不变（fallback / 兼容）。
- **slot**：保留 `#default="{ item, url }"` 模板，原样传 `MediaWaterfallItem` 及其所有事件/slot（video-preview 等）。
- `defineExpose({ refresh })`：原调用 `.renderer()` 改为触发一次响应式重算（如 `forceUpdateKey++` 强制 Masonry 重新布局；多数情况响应式已自动处理，refresh 作为保险）。
- **懒加载**：复用 `lazyload` prop → 传 `getMeta` 的 `lazy` 字段（替代原 vue-waterfall 的 img-selector 懒加载）。
- 删除已失效的 `breakpoints`/`loadProps`/`imgSelector` 等 vue-waterfall 专用 computed（注释或移除；保留对外 props 字段名以兼容，内部忽略）。

## 风险与回滚
- motion-v 的 `layout` 动画在大量 item 时可能略卡；通过 `layoutTransition` prop 可关闭。
- 回滚：保留 vue-waterfall 相关代码于 git 历史，必要时还原。
