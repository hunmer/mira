## 目标
`PluginsDialog.vue` 安装插件时显示百分比进度条，安装中点击可取消安装。

安装链路：`PluginsDialog.vue` → Pinia store `installMarketplacePlugin` → `PluginService.installMarketplacePlugin` → IPC `plugin:install-from-marketplace` → `PluginHandler.handleInstallFromMarketplace`（循环逐文件 `fetch` + 全量 `arrayBuffer()`）。

现状：**无进度上报、无取消**。下载用全量缓冲 fetch、无 AbortSignal、主进程无回推事件通道。

## 设计思路
- **进度**：主进程逐文件**流式读取** `response.body.getReader()`，按累加字节数算百分比（清单已提供每文件 `size` 与目录总 `size`）。通过 `event.sender.send('plugin:install-progress', {...})` 回推到渲染进程，payload 含 `{ pluginId, percent, transferred, total, phase }`（`phase`: `downloading|verifying|done`）。
- **取消**：主进程维护 `Map<pluginId, AbortController>`。新增 IPC `plugin:cancel-install` 触发 `.abort()`，信号传给 `fetch(url,{signal})`。abort 后 `fetch` 抛 AbortError，handler 捕获后**清理半成品目录**并返回 `{ success:false, cancelled:true, message:'已取消' }`。
- **UI**：安装中时把卡片底部按钮区替换为「进度条 + NN% + 取消图标按钮」，点取消调 store 取消方法。

## 文件改动（5 个）

### 1. `packages/mira-client/src/shared/types.ts`
- 在 `ElectronAPI.plugin` 接口（~L441）新增：
  - `cancelInstall: (pluginId: string) => Promise<BaseResponse>`
  - `onInstallProgress?: (cb: (p: PluginInstallProgress) => void) => () => void`
- 新增类型 `PluginInstallProgress { pluginId: string; percent: number; transferred: number; total: number; phase: 'downloading'|'verifying'|'done' }`

### 2. `packages/mira-client/src/preload/preload.ts`（plugin 块 ~L110-113）
- `cancelInstall: (pluginId) => ipcRenderer.invoke('plugin:cancel-install', pluginId)`
- `onInstallProgress: (cb) => { const h=(_e,p)=>cb(p); ipcRenderer.on('plugin:install-progress',h); return ()=>ipcRenderer.removeListener('plugin:install-progress',h) }`（镜像 `pluginWindow.onMessage` 返回反订阅函数的模式）

### 3. `packages/mira-client/src/main/handlers/PluginHandler.ts`
- 新增字段 `private activeInstalls = new Map<string, AbortController>()`
- `registerHandlers()` 注册 `ipcMain.handle('plugin:cancel-install', this.handleCancelInstall.bind(this))`
- 新增 `handleCancelInstall`：按 pluginId 取出 AbortController 调 `abort()`，返回 `{success:true}`
- 改造 `downloadAndVerifyFile(fileUrl, expectedChecksum?, signal?, onChunk?)`：流式读取 `response.body.getReader()`，累加 Buffer，每块调 `onChunk(byteLen)`，再对最终 buffer 校验 sha256；`fetch(url,{signal})`
- 改造 `handleInstallFromMarketplace(event, marketUrl, entry)`：
  - 参数改名 `_event`→`event`，用 `event.sender.send('plugin:install-progress', ...)`
  - 建 AbortController 存入 `activeInstalls`，try/finally 中删除
  - 计算总字节 `total = sum(file.size)` 或 `entry.size`；维护 `transferred`
  - 每文件下载传 `signal` 与 `onChunk=(n)=>{ transferred+=n; 发进度(0~100) }`
  - catch 中：若 `err.name==='AbortError'` → 清理 targetDir，返回 `{success:false, cancelled:true, message:'已取消'}`；其它错误也清理半成品目录
  - 发最终 `phase:'done', percent:100`

### 4. `packages/mira-client/src/renderer/services/PluginService.ts`
- `installMarketplacePlugin(marketUrl, entry)`：逻辑不变（仍 invoke），保留
- 新增 `cancelInstall(pluginId)`：`window.electronAPI.plugin.cancelInstall(pluginId)`
- 新增 `onInstallProgress(cb)`：返回 `window.electronAPI.plugin.onInstallProgress?.(cb)`（非 Electron 环境返回 no-op）

### 5. `packages/mira-client/src/renderer/stores/plugin.ts`
- 新增状态 `marketInstallProgress = ref<Map<string, {percent:number; phase:string}>>(new Map())`
- 在 store 内注册一次 `pluginService.onInstallProgress(p => { marketInstallProgress.value.set(p.pluginId, {percent,phase}); 触发响应式 })`（用新 Map 重新赋值或 `.set` 配合使用处读取）
- `installMarketplacePlugin`：开始时 `marketInstallProgress.set(pluginId,{percent:0,phase:'downloading'})`，结束/失败/取消时 `delete`
- 取消逻辑：需在 store 调用前注册；结果为 `cancelled` 时 toast「已取消」（info，非 error）
- 新增并导出 `cancelMarketInstall(pluginId) => pluginService.cancelInstall(pluginId)`

### 6. `packages/mira-client/src/renderer/components/business/PluginsDialog.vue`
- 从 store 读取 `marketInstallProgress`；新增本地 getter `getInstallPercent(pluginId)`、`getInstallPhase(pluginId)`
- 模板 L356-380（按钮区）：当 `isInstalling(entry.pluginId)` 时，渲染**进度条块**替代原按钮：
  - 细进度条 `div`（宽度 = `percent%`，primary 色）
  - 文字「`NN%`」（`phase==='verifying'` 时显示「校验中」）
  - 取消按钮（material icon `close`/`cancel`，destructive 色），`@click="cancelInstall(entry)"`
- 不安装时保持原 install/update/已安装 三按钮
- 新增 `cancelInstall(entry)` 方法调 `pluginStore.cancelMarketInstall(entry.pluginId)`
- `installMarketplacePlugin` 中：`result.cancelled` → toast severity `info`「已取消」而非 error

## 验收
- 安装时卡片显示 0→100% 进度条；下载→校验阶段文字切换
- 安装中点击取消 → 中断下载、清理目录、toast「已取消」、进度条消失恢复安装按钮
- 取消后/失败后可再次正常安装
- 非 Electron 环境降级：无进度条、按钮仍可用（不阻塞）
