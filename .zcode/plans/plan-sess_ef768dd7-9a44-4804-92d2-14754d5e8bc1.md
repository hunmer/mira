# 发布 @hunmer/vue-masonry 到 npm

## 决策(已与用户确认)
- 包名:`@hunmer/vue-masonry`
- 产物:预编译 dist(vite 库模式 + .d.ts 类型声明)
- `cn()` 依赖:内联零依赖轻量实现,解耦 `@/lib/utils`

## 额外设计(源码分析得出)
1. **去 Tailwind 化**:把 `Masonry.vue` 的 `'relative w-full'`、`LazyCell.vue` 的 `animate-pulse`/`transition-opacity`/`opacity-*` 等全部改写为 `<style scoped>` 等价 CSS,输出 `dist/style.css`,让包脱离 Tailwind 运行时。
2. **移除 mira 内部调试代码**:`LazyCell.vue` 的 `[DEBUG-masonry-preload]` console.debug 段 + `Symbol.for("mira.masonry-preload-debugged")`。
3. **peerDependencies**:`vue ^3.3.0`、`motion-v ^2.0.0`。

## 新建包 `packages/vue-masonry/`
```
src/Masonry.vue      # 去掉 @/lib/utils,Tailwind→scoped style
src/LazyCell.vue     # 去调试代码,Tailwind→scoped style
src/types.ts         # 原样
src/utils.ts         # 内联轻量 cn(string/array/object → string)
src/index.ts         # 原样
vite.config.ts       # lib mode + vite-plugin-dts,external vue/motion-v
tsconfig.json
package.json         # exports(types/import/require)+ ./style.css + sideEffects css
README.md            # 安装/用法/Props 文档
.npmignore
```

## 执行
1. 创建上述全部文件(源码基于 mira-client 复制改造,核心算法逻辑零改动)
2. `pnpm install`(装 vite/@vitejs/plugin-vue/vite-plugin-dts/vue-tsc/typescript)
3. `pnpm build` 验证 dist 产出(.js/.cjs/.d.ts/style.css)
4. `pnpm type-check` 验证类型
5. `npm publish --dry-run` 核对打包内容

## 不在本次范围
- 不改 mira-client 任何代码(后续可独立 PR 把 masonry 引用切到 npm 包)
- 不实际 `npm publish`(需登录,只产出可发布产物)
