# mira-3d-format-preview 预览器重构方案

## 目标
把独立的 3D 预览窗口从原生 CSS 重构为 **shadcn-vue (Tailwind v4 + reka-ui)** 三栏式功能完整预览器：左栏场景树 / 中间画布 / 右栏属性面板，覆盖选中高亮、属性编辑、统计、线框、截图、重置视角、动画播放。

## 新增依赖（写入 package.json）
- `tailwindcss@^4`, `@tailwindcss/vite@^4` — 构建期处理，产物是纯 CSS，兼容 file:// + webSecurity:true
- `reka-ui` — shadcn-vue 的无样式原语（Tabs/Slider/Switch/ScrollArea 等）
- `class-variance-authority`, `clsx`, `tailwind-merge` — Button 等 variant + `cn()`
- `lucide-vue-next` — 工具栏图标
- `tw-animate-css` — 弹层动画（与 mira-client 一致）

> 全部构建期/打包进 dist，运行期自包含，无 CDN 依赖。

## 关键实现点

### 1. TresCanvas 上下文获取（用于重置/截图/适配）
`<TresCanvas @ready="onReady">` → `onReady(ctx)` 保存 `ctx`（含 `camera`/`scene`/`controls`/`renderer`/`sizes`）。
- **重置视角**：Box3.setFromObject(scene) 算 size/center → 设 camera 位置 + `ctx.controls.value.target` + `.update()`。
- **截图**：`ctx.renderer.webGLRenderer.domElement.toDataURL('image/png')` → `<a download>` 下载。
- **OrbitControls**：`make-default`，通过 `ctx.controls` 拿到实例。

### 2. 选中高亮（useHighlight）
参考代码方案，最稳无后处理依赖：
- 选中 mesh → `originalMaterials.set(mesh, mesh.material)` → `mesh.material = highlightMaterial`（wireframe 绿、depthTest:false）。
- 取消/切换 → 恢复 map 中原材质。卸载时 `dispose`。

### 3. 修正 useGLTF v5 错误处理（bug fix）
v5 `useGLTF` 返回 `{ state, isLoading, execute, nodes, materials }`，**无 error**。现有 watch `error` 是空操作。
改为：`watch([state, isLoading])` —— state 有值 emit `loaded`；isLoading 转 false 且 state 仍 null → emit `error`。并用 `execute().catch(emit error)` 兜底。

### 4. 统计（顶点/三角面/对象数）
模型加载后遍历 scene：顶点累加 `geometry.attributes.position.count`；三角面 = `index ? index.count/3 : position.count/3`；mesh/material 计数同参考代码。展示在工具栏 Badge。

### 5. 线框模式（全局）
遍历所有 mesh，切 `material.wireframe = !material.wireframe`（wireframe 是材质自身属性，无需备份）。

### 6. 动画播放
`useAnimations(gltf.animations, modelRef)` → `actions`。若 `animations.length===0` 隐藏 Animations Tab；否则列出 actions，单选播放（切换时 `action.fadeIn` + 旧 `action.fadeOut`），支持暂停。

### 7. 状态管理
单窗口小应用，用 `useViewerStore()`（模块级 reactive 单例）集中管理 selectedObject/Material、stats、wireframe、animations，各组件直接 import 读写，避免 prop drilling。3D 画布通过 TresCanvas 内部，scene 操作走 `@ready` 拿到的 ctx。

### 8. 主题
深色为主（3D 预览器惯例），@theme 复用 mira-client 的 dark token（oklch 值），画布背景 `#0b121b`，保证与宿主视觉一致。

## 验收步骤
1. `cd online_client_plugins/plugins/mira-3d-format-preview && pnpm install && pnpm run build` 构建成功。
2. 从 Mira 媒体网格双击一个 .glb/.gltf → 打开预览窗口。
3. 检查：三栏布局、左栏 Mesh/材质列表可点击选中（画布中高亮）、右栏属性可编辑（位置/颜色/金属度/粗糙度实时生效）、工具栏线框/截图/重置视角可用、统计 Badge 显示顶点/面数。
4. 若模型带动画：Animations Tab 出现并可播放切换。
