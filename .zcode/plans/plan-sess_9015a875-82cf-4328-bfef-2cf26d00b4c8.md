# 实现方案

## 目标
在 `HomeHeader.vue` 头像菜单中：
1. 将 **Playground** 和 **开发者工具** 移到新增的 **「高级」** 子菜单下
2. 在「高级」下新增 **「服务端」** 入口（仅 `environment.isElectron` 时展示）
3. 点击「服务端」弹出对话框，通过 **SSE** 拉取后端最近 100 条日志，并提供 **启用 / 停止 / 重启** 控制

---

## 改动总览（4 个领域）

### A. 后端 (mira-app-server) — 新增 SSE 日志端点 + 环形缓冲

**`packages/mira-app-server/src/services/LogRingBuffer.ts`** (新建)
- 单例环形缓冲类，容量 100
- `push(level, line)` 追加一条日志（带时间戳）；超容量丢弃最旧
- `recent()` 返回当前缓冲区快照
- `subscribe(fn)` / `unsubscribe(fn)` 订阅新日志推送

**`packages/mira-app-server/src/services/logCapture.ts`** (新建)
- `installLogCapture()`：在服务器启动时调用一次，monkey-patch `console.log` / `console.error` / `console.warn`
- 每条调用：① 推入 ring buffer ② 调用原始方法（保证 `service.log` 经 detached 进程 stdio 重定向继续工作）

**`packages/mira-app-server/src/HttpServer.ts`** (修改)
- 在 `setupRoutes()` 里 `/health` 附近新增 SSE 端点：
  - `GET /api/logs/stream`：设置 `Content-Type: text/event-stream`、`Cache-Control: no-cache`、`Connection: keep-alive`
  - 立即发送 `event: history` + `data: JSON(ringBuffer.recent())`（最近 100 条）
  - 注册 subscribe，新日志通过 `res.write('data: ...\n\n')` 推送
  - `req.on('close')` 时 unsubscribe，防止泄漏
- 该端点 **不挂权限中间件**（与 `/health` 一致，本地控制台用）

**`packages/mira-app-server/src/index.ts`** (修改)
- 在 `main()` 启动早期调用 `installLogCapture()`，确保启动日志（🚀 Starting / port / ✅ started）也被捕获，SSE 连上即可拿到历史

### B. Electron 主进程 — 新增 server-control IPC

**`packages/mira-client/src/main/services/LocalServerService.ts`** (修改)
- 新增 `restartLocalServer()` = `runLocalServerScript('stop')` + `runLocalServerScript('start')`（重置 `serverStartPromise = null`）
- 新增 `getLocalServerStatus()`：调用 `runLocalServerScript('status')`，解析脚本输出的 JSON（含 healthy/managed/pid），返回结构化结果
- 导出 `runLocalServerScript` 已有，复用

**`packages/mira-client/src/main/ipc/ServerControlHandlers.ts`** (新建)
- IPC 通道：
  - `server-control:start` → `runLocalServerScript('start', { onOutput })`
  - `server-control:stop` → `runLocalServerScript('stop')`
  - `server-control:restart` → 先 stop 再 start，过程中推送 `server-control:progress` 事件
  - `server-control:status` → `getLocalServerStatus()`
- 启停命令的 stdout/stderr 行通过 `event.sender.send('server-control:progress', { line })` 实时推送给渲染进程（供对话框显示动作反馈）
- 风格/结构对齐 `ServerDeployHandlers.ts`

**`packages/mira-client/src/main/ipc/handlers.ts`** (修改)
- 实例化 `new ServerControlHandlers()`
- `removeAllHandlers()` 中清理 `server-control:*` 监听

**`packages/mira-client/src/preload/preload.ts`** (修改)
- 新增 `serverControl: { start(), stop(), restart(), status(), onProgress(cb), removeProgressListener() }`，全部走 `ipcRenderer.invoke` / `ipcRenderer.on`

**`packages/mira-client/src/shared/types.ts`** (修改)
- 在 `ElectronAPI` 接口加 `serverControl` 类型定义（对齐 serverDeploy 写法）

### C. 渲染进程 — 菜单重构 + 对话框

**`packages/mira-client/src/renderer/views/HomeView/HomeHeader.vue`** (修改 — 主要工作)
- 把头像菜单从自定义 `Dropdown`（Popover 包装）**重写为 shadcn `DropdownMenu`**
  - `DropdownMenu` / `DropdownMenuTrigger`（头像按钮）/ `DropdownMenuContent`
  - 用户信息块用 `DropdownMenuLabel`
  - 上传 / 插件 / 快捷键 / 应用设置 → `DropdownMenuItem`
  - **`DropdownMenuSub`**：「高级」
    - `DropdownMenuSubTrigger`「高级」
    - `DropdownMenuSubContent` 内放：Playground / 开发者工具 / **服务端**（`v-if="environment.isElectron"`）
  - 分隔符 `DropdownMenuSeparator`，退出登录 `DropdownMenuItem`
- 新增 `showServerDialog = ref(false)`；点「服务端」→ `showServerDialog = true`
- 模板末尾内嵌 `<ServerControlDialog v-model:open="showServerDialog" />`（自包含，不经 HomeView）
- 保留 `openDashboard` 逻辑不变

**`packages/mira-client/src/renderer/components/business/ServerControlDialog.vue`** (新建)
- 基于 `@/components/ui/dialog` 的 `Dialog`，`v-model:open` 控制
- 顶部状态栏：健康状态徽标（来自 `status()`）+ PID
- 控制按钮区：**启用** / **停止** / **重启**（用 `@/components/ui/button` 的 `Button`），点击调用 `window.electronAPI.serverControl.*`，按钮在动作执行中 disabled
- 日志区：`<pre>` 滚动容器，等宽字体，自动滚动到底部
- SSE 连接逻辑（onMounted / watch open）：
  - `const base = miraSDKService.getConnectionConfig()?.serverUrl`
  - `const es = new EventSource(\`${base}/api/logs/stream\`)`
  - `es.addEventListener('history', e => { logs = JSON.parse(e.data) })`
  - `es.onmessage = e => logs.push(JSON.parse(e.data))`
  - `es.onerror` → 标记断连、指数退避重连（上限）
  - 关闭对话框 / onUnmounted → `es.close()`
- 监听 `server-control:progress` 把启停动作的 stdout 行也追加到日志区
- 自动刷新状态：启动/重启后轮询 `status()` 几次直到 healthy

### D. 校验
- 类型检查：`cd packages/mira-client && npm run build`（或 typecheck 脚本）确认 preload / types / Vue 无类型错误
- 后端类型检查：`cd packages/mira-app-server && npm run build`
- 手动验证清单（不自动执行，写进交付说明）：
  - 菜单「高级」展开含 Playground / 开发者工具 / 服务端
  - 非 electron 环境无「服务端」项
  - 对话框能收到历史 100 条 + 实时新日志
  - 启用/停止/重启三个按钮工作正常，日志区显示动作反馈

## 关键设计决策
- **SSE 在后端实现**（用户选择）：环形缓冲 + console 拦截，兼顾「最近100条」与实时推送，重启后新进程缓冲独立
- **shadcn DropdownMenu + DropdownMenuSub**（用户选择）：原生二级菜单交互更标准，需把现有 Popover 菜单整体迁移
- **对话框自包含在 HomeHeader 内**（用户选择）：不走 HomeView/HomeDialogs，HomeHeader 内部 ref 控制
- **IPC 通道独立为 `server-control:*`**：与 `server-deploy:*`（npm 安装/部署）职责分离，避免污染
- **restart = stop + start**：复用现有脚本命令，无需扩展 `mira-server-service.mjs`
- **SSE 不鉴权**：与 `/health` 同级，仅本地 127.0.0.1 控制台使用

## 不改动的部分
- `mira-server-service.mjs`（脚本本身不加 restart 命令，靠 stop+start 组合）
- HomeView / HomeDialogs（对话框自包含在 HomeHeader）
- 现有 `server-deploy` / `server-autostart` IPC
