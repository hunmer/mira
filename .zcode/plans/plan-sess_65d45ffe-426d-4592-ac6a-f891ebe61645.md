## 目标
①扩展服务端 `plugins.json` 字段并持久化插件 meta（含图标）；②`plugins.recommend.json` 每条目加可选 `registry`；③安装/上传后从 `package.json` 提取 meta（含 icon）保存到 `plugins.json`；④dashboard 本地插件列表显示图标；⑤搜索栏右侧加【检查更新】按钮，点击同步 package.json 信息到 plugins.json。

---

## 1. 服务端 `ServerPluginManager.ts`

**扩展 `PluginConfig`**（向后兼容，新字段全可选）：
```ts
export interface PluginConfig {
  name: string; enabled: boolean; path: string;
  // 新增：从 package.json 提取并持久化
  version?: string; description?: string; author?: string; main?: string;
  icon?: string | null; title?: string; category?: string; tags?: string[];
  registry?: string; installedAt?: string;
}
```

**新增 `extractPluginMeta(pluginDir)`**：抽出 getPluginsList 现有 icon 逻辑（icon 文件 `icon.{png,svg,...}` → `/api/plugins/<name>/icon.ext` ＞ `mira.icon` ＞ 顶层 `icon`），并一并提取 version/description/author/main/title/category/tags，返回 `Partial<PluginConfig>`。

**`addPlugin(config)`**：调用方传基础字段（name/enabled/path/registry），方法内部对缺失的 meta 字段调用 `extractPluginMeta(path)` 自动补全并持久化（含 `installedAt`）。这样 install/upload 端点无需各自重复提取逻辑。

**`getPluginsList()`**：改为「plugins.json 持久化字段优先，缺失字段 fallback 读 package.json 补全」；icon 解析逻辑不变。兼容老 plugins.json（只有 name/enabled/path）。

**新增 `syncPluginsMeta()`**：遍历 plugins.json 所有插件，重新 `extractPluginMeta` 刷新 meta 字段（保留 name/enabled/path/registry），写回 plugins.json，返回更新条数。供【检查更新】调用。

## 2. 服务端 `PluginRoutes.ts`

- **install（npm）端点**：body 增加可选 `registry`；若提供则直接作为 `npm install --registry <registry>`，否则维持现有 `npmSource` 映射。addPlugin 时把 registry 一并传入（meta 由 addPlugin 自动提取持久化）。
- **upload 端点**：移除第一个重复定义的死代码 `/upload`（368-513，被第二个覆盖从未生效），保留第二个并让其 addPlugin 自动提取 meta。
- **新增 `POST /sync-meta`** `{ libraryId }`：调用 `pluginManager.syncPluginsMeta()`，返回 `{ success, count }`。

## 3. 脚本与 `plugins.recommend.json`

- `publish-plugins.ps1`：生成 recommend.json 时每条目加 `"registry": ""`（空，可手填定制源）。
- 重新生成 `plugins/plugins/plugins.recommend.json`（含 registry 字段）。

## 4. dashboard 前端

- `api/modules/plugin.ts`：`install` 支持 `registry?` 参数；新增 `syncMeta(libraryId)`。
- `plugin/index.vue`：
  - `StorePlugin` 类型加 `registry?`；`installFromStore` 把 `registry` 透传给 install API。
  - 搜索栏右侧加【检查更新】按钮（`RiRefreshLine`），点击调 `syncMeta(activeTab)`，成功 toast + `loadPlugins()` 刷新。
- 本地图标：getPluginsList 已返回 icon，主网格已支持 emoji/URL 渲染；持久化后 icon 字段稳定传递，本地列表即可显示。

## 5. 验证
- 改动 `mira-app-server`（依赖 mira-app-core 但本次不改 core 接口，无需 core rebuild；仅 server `pnpm install` 自身 + 用 procm 重启服务）。
- `vue-tsc -b` 校验前端。
- 手动：安装一个插件 → 查看 plugins.json 含 icon/title/version 等；dashboard 本地列表显示图标；点【检查更新】刷新 meta。
