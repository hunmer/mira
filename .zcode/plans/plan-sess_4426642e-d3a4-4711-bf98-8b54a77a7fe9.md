## Breadcrumb Navigation for MediaTabListView

Replace the footer "route status" block (lines 271–280, currently a static icon + tab label) with an interactive breadcrumb showing the folder/tag hierarchy. Clicking a parent crumb opens that folder/tag's tab.

### Behavior
- **Folder tab** → `全部文件 / ParentFolder / ChildFolder` (walked up via `Folder.parent_id` in `useFolderStore().folders`). Last = current (non-clickable).
- **Tag tab** → `全部文件 / 标签：foo` (tags are flat — single level).
- **All/Uncategorized/Untagged tabs** → just `全部文件` / `未分类` / `未标签` (single, non-clickable crumb).
- **Trash tab** → `回收站` (single crumb).
- Root crumb `全部文件` always opens the all-files tab (via `createTabFromFolder({ id: 'all' }, libraryId)`); intermediate folder crumbs open that folder's tab (`createTabFromFolder({ id, title }, libraryId)`), relying on its built-in dedup/switch.

### Changes

**1. New component: `src/renderer/components/common/Breadcrumb.vue`**
- Props: `items: BreadcrumbItem[]` (reuses the **existing** `BreadcrumbItem` interface from `controllers/HomeController/types.ts`).
- Renders: crumb + `chevron_right` separators; every crumb except the **last** is a clickable button (`text-primary hover:underline`); last crumb is plain `text-foreground font-medium`. Icons rendered with `material-icons` when `item.icon` is set.
- Emits `@select="item"`.

**2. `MediaTabListView.vue` — script: build crumbs + import dependencies**
- Import `useTabs` (from `@renderer/composables/useTabs`), `useFolderStore`, `useTagStore` (already imported), the new `Breadcrumb` component, and `BreadcrumbItem` type.
- New computed `breadcrumbItems: BreadcrumbItem[]`:
  - Root: always `{ id: 'all', label: '全部文件', icon: 'folder' }` for folder/tag/special tabs (not for trash).
  - For `props.filters.folder` (number): look up the folder in `folderStore.folders`, walk `parent_id` upward (cycle-guarded with a `Set`), unshift each `{ id: 'folder-'+f.id, label: f.title, icon: 'folder' }`.
  - For `props.filters.tags` (FilterRule `{ selectedValues }`): map selected values → tag titles from `tagStore.tags`, push `{ id: 'tag-'+tagId, label: '标签：'+title, icon: 'label' }`.
  - Trash: `[{ id: 'trash', label: '回收站', icon: 'delete' }]`.
  - Mark last item `active: true`.
- New handler `handleBreadcrumbClick(item)`:
  - `item.id === 'all'` → `useTabs().createTabFromFolder({ id: 'all' }, props.libraryId)`.
  - `item.id.startsWith('folder-')` → `createTabFromFolder({ id: itemId, title: item.label }, props.libraryId)`.
  - `item.id.startsWith('tag-')` → `createTabFromTag({ id: itemId, title: item.label }, props.libraryId)`.
  - (createTabFromFolder/Tag dedupe+switch internally.)

**3. `MediaTabListView.vue` — template: replace footer block (lines 271–279)**
Replace the existing icon+label `<div>` with:
```html
<!-- 路由状态 / 面包屑导航 -->
<Breadcrumb
  :items="breadcrumbItems"
  @select="handleBreadcrumbClick"
/>
```
Keeps the sibling "N 个文件" span (lines 281–286) untouched.

### Verification
- Open a **nested folder** → breadcrumb shows `全部文件 / Parent / Child`; click `全部文件` → all-files tab opens; click `Parent` → parent folder tab opens.
- Open a **tag** → `全部文件 / 标签：foo`; click root → all-files tab.
- Open **全部文件 / 未分类 / 未标签 / 回收站** → single non-clickable crumb each.
- No regression in footer file-count / pagination / column-slider (those rows unchanged).
