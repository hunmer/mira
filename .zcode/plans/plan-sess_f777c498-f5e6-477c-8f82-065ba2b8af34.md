# FilterBar 增加 metadata 过滤（尺寸/时长）实施方案

## 设计决策（基于用户确认）
- **UI 形态**：合并为单个「metadata」过滤项，内部 RadioGroup 切换"尺寸/时长"两个子模式
- **联动**：不联动 category，始终显示。后端 SQL 自动过滤掉无对应字段的文件（如图片无 duration，`json_extract` 返回 NULL，比较为 falsy 自动排除）
- **预设 + 自定义**：各子模式都提供预设档位 + 自定义 min/max

## 改动清单

### 1. 后端 SQL（核心）— `packages/mira-app-core/src/storage/sqlite/mixins/FileOperations.ts`
在 `getFiles` 的 `custom_fields` 分支后（约 318 行）新增 metadata 过滤分支：
```ts
// 尺寸（按最长边 MAX(width, height)）
const dimMin = filters.metadata_dim_min;
const dimMax = filters.metadata_dim_max;
if (dimMin !== undefined || dimMax !== undefined) {
  const longest = `MAX(CAST(json_extract(metadata, '$.width') AS REAL), CAST(json_extract(metadata, '$.height') AS REAL))`;
  if (dimMin !== undefined) { whereClauses.push(`${longest} >= ?`); params.push(dimMin); }
  if (dimMax !== undefined) { whereClauses.push(`${longest} <= ?`); params.push(dimMax); }
}
// 时长（秒）
if (filters.metadata_duration_min !== undefined) {
  whereClauses.push(`CAST(json_extract(metadata, '$.duration') AS REAL) >= ?`);
  params.push(filters.metadata_duration_min);
}
if (filters.metadata_duration_max !== undefined) {
  whereClauses.push(`CAST(json_extract(metadata, '$.duration') AS REAL) <= ?`);
  params.push(filters.metadata_duration_max);
}
```
- `MAX(x,y)` 是 SQLite scalar 函数（非聚合），自动忽略 NULL 参数；width/height 都为 NULL 时返回 NULL，比较为 falsy，正确排除无尺寸字段的文件。
- CAST AS REAL 确保 exiftool 返回的字符串数值（如 "1920"）正确数值比较。
- 顺便删掉第 196 行遗留的 `console.log({filters})` 调试输出。

### 5. FilterBar.vue UI + 逻辑
- **模板**：在 `v-else-if="filter.type === 'category'"` 后新增 `v-else-if="filter.type === 'metadata'"` 分支：
  - 顶部 RadioGroup：尺寸 / 时长（切换 `filter.metaField`）
  - 尺寸模式下：RadioGroup 预设（小/标清/高清/超高清/自定义）+ 自定义 min/max 输入（px）
  - 时长模式下：RadioGroup 预设（短/中/长/超长/自定义）+ 自定义 min/max 输入（秒）
- **预设常量**（组件内 computed）：
  - `dimensionPresets`：small(<720)、medium(720-1080)、large(1080-2160)、huge(≥2160)
  - `durationPresets`：short(<60s)、medium(60-600)、long(600-3600)、huge(≥3600)
- **handler**：
  - `handleMetaFieldChange(filter, mode)` — 切换子模式时清空另一模式的范围字段
  - `handleMetaPresetChange(filter, presetId)` — 选预设时写 `metaDimMin/Max` 或 `metaDurMin/Max`（沿用 size 预设模式）
  - `updateCustomMetaRange(filter)` — 自定义输入时同步到 meta*Min/Max
- **hasActiveFilters / getActiveFilterCount**：新增 `case 'metadata'`，检查任一 meta*Min/Max 非空
- **clearFilter**：追加清空 metaField、selectedMetaPreset、metaDimMin/Max、metaDurMin/Max、customDimMin/Max、customDurMin/Max

### 6. 查询参数转换 — `packages/mira-client/src/renderer/stores/media.ts`
在 switch(filterRule.id) 的 `case 'title'` 后新增：
```ts
case 'metadata':

```

## 风险/边界
- metadata 列无索引，大库下全表扫描；本次不建索引（最小改动），后续优化可加生成列 + 索引
- exiftool 未安装时 metadata 为空，过滤会排除这些文件（符合预期）
- 不修改 MCP/CLI 入口（用户未要求，保持最小改动）
