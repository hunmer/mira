## 实现计划：HomeSidebar 导入入口 + FileUploadDialog 本地文件夹结构展示

### 概念澄清（已与你确认）
- **左侧新增的本地 FolderTreeComponent**：展示从本地导入的文件夹结构，纯浏览/筛选，**不参与上传**，不在服务器创建文件夹。
- **右侧原有的素材库文件夹/标签树**：是素材的**元数据**（folderId/tags），上传 metadata 仍只带用户在这里选的值。文件夹创建逻辑完全不动。

---

### Part 0：新增递归读取本地目录树的 IPC（main → preload → types）

本地文件只有绝对路径，上传走 SDK 需要字节，因此需要读取目录树 + 按路径读字节的能力。

1. **`src/main/ipc/FileSystemHandlers.ts`**
   - 注册 `ipcMain.handle('fs:readDirTree', ...)`，递归遍历目录，返回树形结构：
     ```ts
     interface LocalFsNode { name: string; path: string; isDir: boolean; children?: LocalFsNode[] }
     ```
   - 用 `fs.promises.readdir(dir, { withFileTypes: true })` 递归，对文件记录大小/扩展名（供预览类型判断），跳过隐藏文件/常见忽略目录（如 `.git`、`node_modules`）。
   - 再注册 `fs:readFileBytes(path)`：用 `fs.promises.readFile(path)` 返回 Buffer/ArrayBuffer，供按路径构造 `File` 上传。
2. **`src/preload/preload.ts`** 的 `fs` 块新增 `readDirTree(dirPath)`、`readFileBytes(filePath)`。
3. **`src/shared/types.ts`** 的 `ElectronAPI.fs` 加这两个方法的类型签名。

   - 预留扩展位（按钮列表"横向图标按钮列表"语义，可后续加更多按钮）。

### Part 2：FileUploadDialog 三栏改造（左侧本地树 + 中间文件列表 + 右侧元数据面板）

**布局**：`flex-1 flex gap-4` 内改为三栏：
- 左栏 `w-60`：新 `<FolderTreeComponent>`（item-type="folder"），顶层显示【全部】，加一个【未分组】分类，下面是导入的本地目录层级。
- 中栏 `flex-1`：现有的待上传文件网格/拖拽区（**整体保留不动**）。
- 右栏 `w-72`：现有素材库文件夹树 + 标签树（**整体保留不动**）。

**数据流**：
1. **`types.ts`**：
   - `PendingFile` 增加可选字段 `localPath?: string`（本地绝对路径，用于按路径上传）和 `localDirPath?: string`（所属本地目录，用于左侧树筛选）。
   - `Props` 增加 `initialLocalTree?: { rootPath: string; tree: LocalFsNode[] }`。
   - 导出 `LocalFsNode` 接口（与 Part 0 IPC 返回一致）。
2. **`useFolderTagPanel.ts`** 新增（或新建 `useLocalTree.ts` composable）：
   - `localTreeData` computed：把 `LocalFsNode[]` 转成 `FolderItem[]`（id 用本地 path，icon='folder'，count=该目录文件数）。
   - `selectedLocalDir` ref（存选中的本地目录 path，或 `'all'` / `'ungrouped'`）。
3. **`useFileManagement.ts`**：
   - `addFiles` 支持传入 `localPath`/`localDirPath`（导入场景）或留空（手动添加，归入【未分组】）。
   - 新增 `getFilesByLocalDir(dirPath)`：供中间文件列表按左侧选中目录筛选展示。
   - 导入时：对 `LocalFsNode` 树做一次扁平化，取出所有 `isDir===false` 的节点，通过 `fs:readFileBytes` 读取字节构造 `File`（含正确 name/type），批量 `addFiles(..., { localDirPath })`。读字节较重，做成异步并发（限制并发，或惰性：先只入列元信息，上传前再读字节——**采用惰性**，避免大文件夹卡顿）。
4. **`useUploadQueue.ts`**：上传时若 `pendingFile.file` 为惰性占位（无 size/字节）则先 `fs:readFileBytes(localPath)` 构造真正 `File`，再走原 `mediaStore.uploadFile`。metadata 仍只由 `folderId`/`tags`（右侧元数据面板）决定，**本地树不参与 metadata**。
5. **`useFileUploadDialog.ts`**：
   - 打开时若传入 `initialLocalTree`：构建本地树、扁平化文件、`addFiles` 入列（带 localDirPath，惰性）。
   - 新增 `handleLocalTreeSelect(node)`：设置 `selectedLocalDir`，中间列表据此切换显示。
   - 中间文件列表的 `pendingFiles` 改为 `filteredPendingFiles` computed（按 `selectedLocalDir` 过滤）。
6. **`FileUploadDialog.vue`** 模板：
   - 左栏新增 FolderTreeComponent，`baseCategoriesConfig` 自定义为 `[{id:'all',label:'全部',icon:'folder_open'}, {id:'ungrouped',label:'未分组',icon:'folder_special'}]`，`:folders="localTreeData"`，`@select="handleLocalTreeSelect"`。
   - 中间列表数据源从 `pendingFiles` 换成 `filteredPendingFiles`（清空全部、计数文案相应调整：顶部计数显示当前筛选数 / 总数）。
   - 顶部队列状态、底部素材库选择器与"开始上传"按钮、右栏元数据面板保持原样。

### Part 3：上传统一提交
- 点击【开始上传】→ `startUpload`（保留现有逻辑）：快照**全部** `pendingFiles`（不受左侧筛选影响）→ `enqueueFiles` → 队列逐个按需读字节+上传，metadata 用每个文件右侧元数据面板设的 `folderId`/`tags`。
- 上传完成自动关闭对话框（保留现有 watch `uploadingFileIds.size===0` 逻辑）。
