## 目标
将 PlaygroundPanel 从 SettingsDialog 中抽离为独立的 `/playground` 路由页面，在 HomeHeader 头像下拉菜单中新增入口，点击切换到 playground 路由。

## 改动清单（5 个文件）

### 1. 新建 `packages/mira-client/src/renderer/views/PlaygroundView.vue`
参考 `SettingsView.vue` 的结构，构建带返回按钮的完整页面：
- 顶部 header：左侧 `arrow_back` 按钮（`router.go(-1)`）+ `science` 图标 + "Playground" 标题
- 主区域直接渲染 `<PlaygroundPanel />`（复用现有组件，不改动其内部逻辑）
- 顶部右侧可留空或后续扩展，保持简洁

### 2. `packages/mira-client/src/renderer/router/index.ts`
- 新增路由记录：
  ```ts
  {
    path: '/playground',
    name: 'Playground',
    component: () => import('../views/PlaygroundView.vue'),
    meta: { title: 'Playground', requiresAuth: true, requiresConnection: true, icon: 'science' }
  }
  ```
  （`requiresAuth` + `requiresConnection` 与 Home 一致，确保进入前完成应用初始化）
- 新增工具函数 `navigateToPlayground`

### 3. `packages/mira-client/src/renderer/views/HomeView/HomeHeader.vue`
在头像下拉菜单的「快捷键设置」与「应用设置」之间（或紧邻「应用设置」）新增一项「Playground」：
- icon: `science`
- 点击：`router.push({ name: 'Playground' })`（HomeHeader 中 `import { useRouter } from 'vue-router'` 后 `const router = useRouter()`）
- 样式复用相邻菜单项的 `w-full flex items-center space-x-2 p-2 text-muted-foreground hover:text-foreground hover:bg-primary/5 rounded-lg text-sm transition-colors`
- 不新增 emit 事件，直接在组件内 `router.push`（与「开发者工具」直接调用 `shortcutService.executeAction` 的就地处理风格一致）

### 4. `packages/mira-client/src/renderer/components/business/SettingsDialog.vue`
移除 playground：
- 删除 `import PlaygroundPanel from '../../views/settings/PlaygroundPanel.vue'`
- 删除 `componentMap` 中的 `playground: PlaygroundPanel` 行

### 5. `packages/mira-client/src/renderer/views/settings/settingsConfig.ts`
从 `settingSections` 数组中删除 `{ id: 'playground', name: 'Playground', icon: 'science' }` 这一行。

## 不改动的部分
- `PlaygroundPanel.vue` 内部逻辑完全不变（通知/表单 demo、所有交互、isElectron 判断均保留）
- `HomeDialogs.vue` / `HomeView/index.vue` 无需改动（playground 改为路由跳转，不走 dialog 体系）
- `SettingsDialog.vue` 的 `<aside>` 左侧分类面板由 `settingSections` 驱动，删除配置项后该项自动消失，无需改 template

## 验证方式
- 启动开发服务器，进入主页，点击右上角头像 → 下拉菜单出现 "Playground"
- 点击后 URL 变为 `#/playground`，显示完整页面（header + 通知/表单 tab）
- 点击返回按钮回到主页
- 打开「应用设置」对话框，确认左侧分类不再有 Playground 项，且 Playground 入口仅在头像菜单
