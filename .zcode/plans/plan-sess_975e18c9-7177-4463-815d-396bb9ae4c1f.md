# 悬浮球（Floating Ball）窗口实现方案

参考 `docs/floating-window-extension.md` 的三层架构，基于已有的 `FloatingWindowHandler` 通用基类，新增一个**单实例悬浮球窗口**。核心能力：自由拖拽 + 位置持久化/恢复 + 接收文件拖放 + 触发 `FileUploadDialog` + 设置面板（开关、点击行为、重置位置）。

## 关键技术决策（已验证）

1. **文件拖放 → 真实路径**：Electron 38 的 `webUtils.getPathForFile(file)` 可在 **sandboxed preload** 中运行（官方支持）。悬浮球的 preload 用它把拖入的 `File[]` 转成 `LocalFsNode[]`（含 `path`/`name`/`size`/`ext`），经 MessagePort 传给主进程 → 转发主渲染进程 → 走 `FileUploadDialog` 已有的 `addLocalFiles`（惰性读取字节）链路。无需读取文件字节两次。
2. **自定义拖拽窗口**：复用 `NotificationWindowHandlers` 的 `nt-drag-*` JS 拖拽模式（rAF 节流 + 主进程 `setPosition`），但**不做轴向/方向限制**（悬浮球可全向自由移动），松手后 `clampToScreen` + 持久化坐标。
3. **位置持久化**：通过主进程 IPC `floating-ball:set-position` / `get-state`，写入 `app.getPath('userData')/floating-ball-state.json`（JSON 文件）。**不污染** `AppSettings`（位置是窗口运行态，与界面设置解耦）。重置位置 = 删除该文件 + `positionWindow('bottom-right')` + `clampToScreen`。
4. **单实例**：`ipcChannelPrefix: 'floating-ball'`，`role: 'floating-ball'`。窗口 `skipTaskbar: true`，应用启动时不自动创建，由设置开关按需 show。
5. **点击行为可配置**：新增设置项 `floatingBallClickAction: 'openUpload' | 'toggleMain'`，设置面板用 `Select` 切换。

## 新增文件

### 1. 渲染层：`src/floating-ball-window/`

**`floating-ball-window.html`** — 仿 `notification-window.html`：引用 `../floating-window/vendor/vue.global.prod.js` + `floating-window-core.js`；Material Icons 字体路径 `../../assets/fonts/material-icons.ttf`；主题变量；圆形球样式（`#floating-ball` 56×56，玻璃质感渐变 + box-shadow，hover 放大，dragging 时阴影增强，拖入文件时高亮边框 `.is-dragover`）。

**`floating-ball-window.js`** — Vue app：
- `createBridge({ role: 'floating-ball', onMessage })`
- 数据：`isDragging`、`isDragover`、`dragMoved`、`dragStartCursor`
- `mousedown` → 发 `nt-drag-start`（记录 `e.screenX/Y`），`document` 上 `mousemove`(rAF) → 发 `nt-drag-move {deltaX,deltaY}`，`mouseup` → 发 `nt-drag-end`
- **文件接收**：`dragenter/over` → `e.preventDefault()` + `isDragover=true`；`drop` → 遍历 `e.dataTransfer.files`，用暴露的 `window.electronAPI.getPathForFile(f)` 取真实路径，拼成 `{name,path,size,ext,isDir:false}[]`，发 `fb-file-drop { files }`，`isDragover=false`
- `click` → 若 `dragMoved` 清除并忽略，否则发 `fb-click`
- 图标用 Material Icons（如 `add` / `upload`），带呼吸光晕动画

### 2. Preload：`src/preload/floating-ball-preload.js`
仿 `notification-preload.js`。关键扩展：用 `const { webUtils } = require('electron')`，`contextBridge.exposeInMainWorld('electronAPI', { getPathForFile: (f) => webUtils.getPathForFile(f) })`，并保留 `connect` MessagePort 转发逻辑。

### 3. 主进程处理器：`src/main/ipc/FloatingBallWindowHandlers.ts`
单实例 `FloatingWindowHandler` 子类：
- options: `{ name:'floating-ball', title:'Mira 悬浮球', width:64, height:64, movable:true, alwaysOnTop:true, skipTaskbar:true, showLoading:false, htmlFileName:'floating-ball-window.html', htmlDirName:'floating-ball-window', preloadFileName:'floating-ball-preload.js', ipcChannelPrefix:'floating-ball', role:'floating-ball' }`
- 覆盖 `createWindowInternal`：调用 super，创建后**恢复上次位置**（读 state 文件 → `setPosition`，失败则 `computePosition('bottom-right')`）
- 覆盖 `onReadyToShow`：`doShow()`
- `messageHandlers`：
  - `nt-drag-start`：记录 `win.getBounds()` 起点
  - `nt-drag-move`：`deltaX/deltaY` 全向应用（无轴向/符号限制）→ `setPosition`，节流交给渲染层 rAF
  - `nt-drag-end`：`clampToScreen()` + 持久化当前 bounds 到 state 文件
  - `fb-click`：根据 `clickAction`（从主渲染进程异步查 `floating-ball:get-click-action` 或由 renderer 下发）决定发 `fb-open-upload` 还是 `fb-toggle-main`
  - `fb-file-drop`：转发主渲染进程 `floating-ball-from-window { type:'file-drop', files }`
- 自有 IPC：`floating-ball:show` / `:hide` / `:toggle` / `:set-position`（重置用）/ `:get-state`
- state 文件读写：`fs.readFileSync/writeFileSync` 到 `app.getPath('userData')/floating-ball-state.json`，结构 `{ x, y }`
- `getMainWindow`：复用 `NotificationWindowHandlers` 的 `aliasName==='Mira'` + 回退查找
- `cleanup()`：destroy 窗口 + 移除所有 `floating-ball:*` handle

### 4. 设置面板：`src/renderer/views/settings/FloatingBallPanel.vue`
仿 `ImportPanel.vue`：
- 顶部标题"悬浮球"
- **启用悬浮球** `Switch`（双向绑定 settings + `saveSettings()`，变更后立即调用 `floatingBall.show()/hide()`）
- **点击悬浮球时** `Select`（`openUpload` / `toggleMain`），保存到 settings
- **位置** 区：显示当前坐标（从 `floatingBall.getState()` 读），【重置位置】按钮 → 调 `floatingBall.setPosition(null)`（主进程清文件 + 回右下角 + clamp）

## 修改文件

### 5. `src/main/ipc/handlers.ts`
- import `FloatingBallWindowHandlers`，新增字段 `floatingBallHandlers`，构造里 `new FloatingBallWindowHandlers()`，`removeAllHandlers()` 里 `this.floatingBallHandlers.cleanup()`。
- 暴露 getter `getFloatingBallHandlers()`。

### 6. `src/preload/preload.ts`（主渲染进程）
在 `electronAPI` 增加：
```ts
floatingBall: {
  show: () => ipcRenderer.invoke('floating-ball:show'),
  hide: () => ipcRenderer.invoke('floating-ball:hide'),
  toggle: () => ipcRenderer.invoke('floating-ball:toggle'),
  setPosition: (pos?: {x,y}|null) => ipcRenderer.invoke('floating-ball:set-position', pos),
  getState: () => ipcRenderer.invoke('floating-ball:get-state'),
}
```

### 7. `src/shared/types.ts`
- 在 `ElectronAPI` 接口加 `floatingBall` 类型块。
- 导出 `FloatingBallPosition = { x: number; y: number }`、`FloatingBallClickAction = 'openUpload' | 'toggleMain'`。

### 8. `src/renderer/stores/settings.ts`
- `AppSettings` 新增：`floatingBallEnabled: boolean`（默认 `false`）、`floatingBallClickAction: 'openUpload' | 'toggleMain'`（默认 `'openUpload'`）。
- 默认 settings 对象 + `resetSettings` 的 `defaultSettings` 都加上这两项。

### 9. `src/renderer/views/settings/settingsConfig.ts`
- `settingSections` 加 `{ id:'floating-ball', name:'悬浮球', icon:'android' }`（或 `bubble_chart`）。

### 10. `src/renderer/components/business/SettingsDialog.vue`
- import `FloatingBallPanel`，`componentMap` 加 `'floating-ball': FloatingBallPanel`。

### 11. `src/renderer/views/HomeView/index.vue`（核心接线）
- 监听 `floating-ball-from-window` IPC：
  - `{type:'file-drop', files}` → 构造 `{ rootPath: '', tree: files }`，设 `uploadInitialTree.value`，`showFileUploadDialog.value=true`（复用现有 `handleImportFolder` 的链路，FileUploadDialog 的 `initialLocalTree` → `addLocalFiles`）
  - `{type:'open-upload'}` → `showFileUploadDialog.value=true`（空列表）
  - `{type:'toggle-main'}` → 调用 `windowNavigation` 的 minimize/show（复用现有窗口控制）
- `onMounted` 里：`settingsStore.loadSettings()` 完成后读 `floatingBallEnabled`，为真则 `window.electronAPI.floatingBall.show()`；`watch(() => settingsStore.settings.floatingBallEnabled, ...)` 响应开关变化。
- `onUnmounted`：`removeAllListeners('floating-ball-from-window')`。

### 12. 构建配置
- `scripts/build-float.js`：`filesToCopy` 追加 `['src/floating-ball-window/floating-ball-window.html','floating-ball-window.html']` 和 `.js` 条目。
- `vite.config.ts`：preload 多入口加 `'floating-ball-preload': 'src/preload/floating-ball-preload.js'`。
- `vite.preload.config.ts`：同样加该入口。

## 验证步骤（实现后）
1. `pnpm type-check`（或 `vue-tsc`）通过。
2. `pnpm build:float` → 确认 `dist-float/floating-ball-window.{html,js}` 存在。
3. `pnpm build:all` 通过（含 `dist-preload/floating-ball-preload.js`）。
4. 启动应用 → 设置开启悬浮球 → 球出现在右下角；拖拽移动后重启应用位置恢复；拖文件到球上 → FileUploadDialog 打开且含文件；重置位置按钮生效。

> 注：本方案不改 `FloatingWindowHandler` 基类，纯增量，零回归风险。所有现有浮动窗口（search/notification）不受影响。
