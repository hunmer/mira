## 概述

为 `mira-browser-extension` 增加「多服务器」与「未选素材库时的卡片网格选择」能力。改造从「单服务器字段」迁移到「多服务器配置列表 + 当前激活服务器」,所有旧逻辑(自动登录 / ensureClient 重建 / verify)平滑兼容。

确认的方案:
1. **服务器切换器**:独立一行服务器栏(状态点 + 可横向滚动 badge 列表 + 右侧管理⚙)
2. **服务器管理**:全屏覆盖视图(列表卡片 + 新增/编辑表单)
3. **素材库切换**:header 下拉(快速切换)与卡片网格(未选库时)并用

---

## 数据模型变更

### `src/shared/types.ts`
新增 `ServerConfig` 类型与 `activeServerId`,并把 serverURL/username/password 标注为迁移用兼容字段:

```ts
export interface ServerConfig {
  id: string;        // crypto.randomUUID()
  name: string;      // 显示名(如「本机开发」)
  serverURL: string; // http://localhost:8081
  username: string;
  password: string;
}
```
`ExtensionSettings` 增加 `servers: ServerConfig[]`、`activeServerId: string`;保留旧 `serverURL/username/password`(迁移期读取,迁移后置空)。
`DEFAULT_SETTINGS` 增加 `servers: []`、`activeServerId: ''`。

> 顶部添加迁移注释说明 serverURL/username/password 为遗留兼容字段。

### 迁移逻辑(放 `useConnection`/`App.vue` onMounted,幂等):
若 `servers` 为空且旧 `serverURL` 非空 → 用旧凭据构造首个 ServerConfig(id 用 activeServerId 或新建),写回 settings。无旧值 → 不自动塞默认服务器(避免凭据污染),首次直接进连接界面手动新增。

## 后端层

### `src/shared/messages.ts`
- 新增 Request:
  - `SERVERS_LIST`(返回 settings.servers + activeServerId)
  - `SERVERS_SAVE`(payload: `{ servers: ServerConfig[] }`)
  - `SERVER_ACTIVATE`(payload: `{ id: string }`:写 activeServerId + 同步 serverURL/username/password 到顶层兼容字段 + 清 session/token → 触发重新登录)
  - `SERVER_TEST`(payload: `{ serverURL, username, password }`:临时建 MiraClient 登录验证,不动全局 client,返回 `{ ok }`)
- 加入 `REQUEST_TYPES` 集合。

### `src/background/message-router.ts`
新增上面 4 个 case 的处理,调用 settings.ts 与 mira-client 的导出函数。

### `src/background/mira-client.ts`
- `ensureClient()`:从 `activeServerId` 找到对应 ServerConfig,用它的 serverURL(而非顶层 serverURL);找不到则回退顶层(兼容)。
- 新增导出 `loginTo(serverURL, username, password)`:不依赖 settings、不污染全局 client/session,仅返回 token 或抛错。`SERVER_TEST` 与激活后的自动登录复用。
- 激活服务器后 `clearSession()` + 重置 currentClient/currentServerURL,确保下一次 withAuth 用新服务器重登。

### `src/ui/composables/useBackground.ts`
新增 `listServers / saveServers / activateServer / testServer` 包装。

## 前端组合式

### `src/ui/composables/useConnection.ts`
- 暴露 `activeServer`(computed:从 settings.servers 按 activeServerId 查)、`switchServer(id)`(调 activateServer → verify)、`servers`(来自 settings)。
- `login` 改造:若当前无 activeServer,登录成功后自动把填入的 URL/账号存为一条新 ServerConfig 并激活(保证手动登录流程仍可用)。
- `verify` 维持:用 activeServer(或顶层兼容字段)登录。

### 新增 `src/ui/composables/useServers.ts`
集中服务器 CRUD:`servers`/`activeServer`/`add`/`update`/`remove`/`activate`/`test`。内部走 useBackground。删除当前激活项时自动切到第一个或退回连接界面。
